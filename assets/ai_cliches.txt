# AI 味词表
#
# 这些词本身没错，错在它们是**叙述者替读者总结感受**，而不是把东西写出来让读者自己
# 感受。模型偏爱它们，因为它们在任何语境里都成立——而"在任何语境里都成立"正是读者
# 说"一股 AI 味"时指的那件事。
#
# ── 格式 ──
#   [分类] 后面跟这一类的修法，会直接显示在诊断报告里
#   !词    铁套话，叙述里出现一次就报
#   词     常见套话，叙述里达到密度阈值才报（见 AI_CLICHE_SOFT_MIN）
#   # 开头是注释，空行忽略
#
# ── 两档的理由 ──
# 「时光荏苒」出现一次就该报，它在任何小说里都是偷懒。
# 「然而」「就在这时」出现一次完全正常，出现六次才是毛病。一刀切会把报告刷满噪音，
# 作者看两次就再也不看了——这比不报更糟。
#
# ── 只查叙述，不查对话 ──
# 人物嘴里说套话是人物特征（一个爱说"命运如此"的角色是立住了的），叙述者说套话才是
# AI 味。检查会先剥掉「」""''里的内容再比对。
#
# ── 改词表 ──
# 自己的补充写进 ai_cliches.author.txt（同目录，格式一样），它不会被任何重建覆盖。
# 这份文件只放跨题材通用的；某个题材专有的套话写进该题材的 .author.txt 规则层。
