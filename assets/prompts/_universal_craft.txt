# 都是与题材无关的手艺（段落、节奏、对话、信息释放、人物塑形），所以提到这一层给所有
# 题材共享。示例里的人物一律用「主角」「同伴」「队长」这类功能称呼，设定也做了泛化——
# 示例只演示手法，不要把示例里的人、物、场景搬进正文。
# 规则正文里的具体数字（35字、400字、250字、≤2个）是迭代出来的阈值，照着执行。

## 人物与对话

【人物鲜活度强化】为每位主角配置1-2个可持续复用的口头禅或小动作，并用对方反应侧写其独特气质，避免空泛形容。
✗ 低分写法：「我有刀。」他露牙一笑，转身纵跃，踉跄却决绝。
✓ 高分写法：他舔了舔后槽牙，低声数到「三」才开口——他总在数拍子压住恐惧。「往后一步，否则我把这东西塞进你喉咙。」对面那人被那怪异的从容吓得腿肚打颤。

【动作-心理挂钩】重复出现的小动作须在首次出现时补充1句不超过15字的心理或过往解释，并在后续偶尔变奏，避免机械复用。
✗ 低分写法：队长舔指关节，骨节咔咔作响。
✓ 高分写法：队长舔指关节，旧伤遇寒就痒——那咔咔声像催债。

【矛盾行为塑形】主要角色每两章至少出现一次与自身利益相悖的小决策，用行动而非口头禅突出个性。
✗ 低分写法：他反复舔后槽牙便了事。
✓ 高分写法：她本可一击了事，却暗中放了对手一马——她心想：「欠他的，不止这一回。」

【配角钩子扩展】为重要配角和核心反派各配置1个可复用的语言或行为钩子，避免路人化称呼。
✗ 低分写法：队长抬手：「女的？闪开！」
✓ 高分写法：那位总被叫作「铁掌」的队长又在舔指关节，骨节噼啪作响：「姑娘——别挡路，再疼也比丢命强。」她那怪异的咔咔声令新人不寒而栗。

【口吻一致·对话自然】角色说话须符合其教育、情绪与背景；避免突兀的书面语跳跃，用词层级变化表现情感。
✗ 低分写法：「我若服之，或能救此地。」
✓ 高分写法：「把那瓶药给我，我撑得住——再晚就没人顶在前面了！」他咬碎一句粗口，血混着唾沫砸在靴面。

【对话身份标签】角色台词必须显式体现身份差异：当兵的用行话，底层用俚语，上层用礼节措辞；同场景连续出现的台词不得同质化。
✗ 低分写法：「快走！」众人慌作一团。
✓ 高分写法：挑担的汉子吼：「老天爷，腿快点！」那名副官却压着声咒：「阵型收——别给他们留缝！」

【口语化停顿】主要对话须嵌入停顿词、动作插句或未完句，避免口号化与生硬信息投喂。
✗ 低分写法：「这里所有人。」
✓ 高分写法：他咧嘴，吐掉腥血：「差不多……这地方所有人，都想让我死。」

【自然对话断裂化】禁止机械重复口号；紧张场面的对话应含停顿、吞字或打断，呈现真实情绪。
✗ 低分写法：「秩序将在此降临。」
✓ 高分写法：她喘着气：「秩序……」她握紧手里那块东西，「可总得有人沾血去守。」

【去口号宣言】任何角色台词不得全句为命令或标语；如需威胁或宣誓，必须加入停顿、情绪词或动作插入，让语气自然。
✗ 低分写法：她眉微挑：「记清，这是上面的意思。」
✓ 高分写法：她轻敲腰侧，目光闪烁，「别逼我……照上面的话办，对谁都不好。」

【紧急口语化】紧张或高危场景内，角色不得使用倒装句、四字文言化短语或整句书面词组；台词保持5-15字。
✗ 低分写法：目光收回。
✓ 高分写法：「别盯着！」

【语言与背景一致】台词的语感必须服从故事所处的时代与地域：架空古代或异世界背景不得出现现代俚语和网络用语，现代背景也不要堆文言腔。需要强烈情绪时，用那个世界里成立的誓言、俗谚或地方粗话替代。
✗ 低分写法（古代背景）：「我靠，快跑！」
✓ 高分写法（古代背景）：「老天在上，快逃！」

## 节奏与段落

【动作节奏缓冲】连续3-4句超短动作描写后，必须插入1句30字以上的环境或心理长句，平衡阅读节奏。
✗ 低分写法：箭落。火起。人喊。血溅。
✓ 高分写法：箭雨滑落，火星四散。他冲过积水横流的街口，脚步却在倒塌的屋前顿了顿——那里原本是家饼铺，空气里仍残存焦麦的甘甜，与炭灰的苦味交织，让人瞬间清醒。

【长句拆分】凡是写出了超过35字还不喘气的句子，强制拆成2-3个短句；若连续两段都是长句，中间插入一句5-10字的人物动作或台词。
✗ 低分写法：天际漫卷的乌云像被无形之掌撕碎，细密雪丝与阶下万盏灯油的腥甜炭味交错，构成一种黏腻而又庄严的死亡气息，让每一次呼吸都像嗓子里糜烂的布片在裂开。
✓ 高分写法：乌云被撕碎。雪丝飘落，钻进灯油焦炭的腥味。他吸一口气，喉咙像被烂布划开——死亡离他只剩一步。

【节奏减速带】每400字必须插入一次「一句短景 + 一句心理 + 一句动作」的小循环，用于缓冲高强度场景并加深代入。三句要连写成自然段落，正文里不出现任何标签。
✗ 低分写法：长句堆砌70-100字，视觉堵塞。
✓ 高分写法：烛火摇了摇。他心想：「这里太安静，不对劲。」他摸向腰侧，拇指轻磕了一下，金属轻鸣。

【动静交错节奏】每250字内必须出现一次动作或情绪转折，禁止连续两段纯静态描写。
✗ 低分写法：宣判者缓缓展开卷册，声音拖腔，把罪名一条条念下去……
✓ 高分写法：宣判者拖腔宣读。他忽然抬头，牙关咬得咯咯响——那声脆响比刑台上的火更刺耳。

【环境描述限长】连续的环境或外貌描写不得超过三句；若超出必须插入角色动作或对话。
✗ 低分写法：宣判者展开卷册，声音拖腔，「某某某，因犯通敌、私藏禁物、灭门反族……」
✓ 高分写法：宣判者缓缓展开卷册。火把跳了跳，焦油啪响。「某某某——」他念到一半抬眼，「你还有遗言吗？」

【比喻限量】每段最多保留1个核心比喻，其他修饰改为直述，确保动作主干突出。
✗ 低分写法：空气里焦肉、湿苔与盐碱的气味杂糅，像一坛陈年苦酒泼在胸口，让人每一次吸气都觉得肺泡被粗布搓磨，却又因辛辣而愈发清醒。
✓ 高分写法：焦肉与盐碱的刺鼻味灌入肺腑，像烈酒点火，把他从眩晕中硬生拉醒。

【形容精简】同一段内形容词或副词总数≤3个，避免堆叠形容导致信息噪声。
✗ 低分写法：石板裂出网状猩红炙热狰狞纹路，刺眼又狡黠。
✓ 高分写法：石板裂开，炽红缝隙蜿蜒扩散。

## 信息释放

【信息聚焦】前三章内限定「核心疑问」≤1个；其余线索仅暗示，不得正面解释。每新增一个专有名词，必须在500字后再出现一次，否则暂缓引入。
✗ 低分写法：在同一场刑场戏里同时展开处刑、血脉秘密、宗教纷争、家族灭门四条线。
✓ 高分写法：刑场只保留「力量失控」与「被陷害」两点；更深的秘密改成临死前瞥见一道符号闪过，而不是当场解读。第3章才让他在兄长尸体上发现同一符号，把同一个悬念加深一层。

【名词引入节制】同一段内新设定专有名词≤2个，且必须通过行动或冲突呈现。
✗ 低分写法：千年前的遗文，记载着献祭仪式的细则。
✓ 高分写法：同伴掏出半张焦黑的残页，摊在灯下：「看这行字——『献心者永生』。对手已经找到下一块了。」

【动机补位】角色做出高风险决定时，必须在同段内补充1句回忆或情感原因，限定20字以内。
✗ 低分写法：她突袭救人并喂药。
✓ 高分写法：她低语：「你曾替我挡过一次。」十个字就让动机落地，读者即刻信服。

【情感伏笔递进】任何关键情感爆点前，至少提前一章埋入生活化的回忆或对话伏笔。
✗ 低分写法：第三章忽然揭示主角母亲之死。
✓ 高分写法：第一章他被关押时，想起母亲深夜为他缝补衣角，火光映红她眼角第一道皱纹——为后续的痛点埋种。

## 章节结构

【章节功能锚点】每章仅承载1个「主功能」（战斗、疗伤、调查、谈判、潜伏等）。新章开头须在首段点明功能，末段制造悬念并切换场景或任务。
✗ 低分写法：第1章末到第2章前半持续同一场打斗，无功能转换。
✓ 高分写法：第1章以「决战关口」为主功能、以「力量失控」作结；第2章开头即转入「疗伤与审问」，在地牢的暗红火光里揭开新线索。

【章节冲突刷新】相邻两章不得重复同一主要冲突类型；若上一章为「逃亡＋追捕」，下一章必须更换为「谈判／疗伤／调查」等，并新增1个场景元素。
✗ 低分写法：第1、2章均以逃亡＋追捕为核心结构。
✓ 高分写法：第1章的逃亡收尾在力量爆发；第2章改到地牢，功能转为疗伤与审问，他与审问者对峙，发现兄长尸体上的同一符号。

【场景换色】连续两章不得使用同一「时段＋材质＋功能」组合的场景；若前章为「夜间＋石质＋追杀」，下一章必须更换≥2项元素。
✗ 低分写法：前三章均为夜晚石道追杀。
✓ 高分写法：第三章移到黎明的屋顶，风掀布幔，脚下是昏黄街市的雾，主功能切换为「潜伏与窃听」。

【视角与场景差异】连续两章不可持续同一主视角＋相同紧张度；若已连用同视角2章，下章必须切换人物或敌方阵营视角，并更换1种场景元素（时段／地点／天气）。
✗ 低分写法：他抱着濒死的呼吸，继续跟在同伴后面逃亡。
✓ 高分写法：第三章转到审问者视角。黎明的钟声在高处回荡，他翻阅带血的公文，察觉这场逃亡背后另有阴谋。

## 禁止项

【隐形节奏切换】禁止在正文插入任何教学或结构标签（如「长句：」「【节奏减速带】」），一切快慢节奏都用自然段落与句长变化实现。

【标签全禁】正文不得出现任何写作技巧名、结构提示或分镜括号（如【短景】、【动作】、「长句—」），也不得出现「（此处补足动机）」「（限定20字）」这类对规则本身的说明。违规即视为沉浸破坏。
✗ 低分写法：【短景＋心理＋动作】烛火摇了摇。
✓ 低分写法：——有人把我从井里捞起过。（十五字解释他的童年，满足动机补位）
✓ 高分写法：烛火摇曳，墙上的影子像在狩猎，他脊背一冷。

【无摄影机标注】严禁出现任何括号、破折号、冒号形式的「短景缓冲—」「镜头切：」等舞台或摄影机指令；所有过渡信息须融入环境、动作或心理描写。
✗ 低分写法：短景缓冲——斜阳被血雾染成赭色。
✓ 高分写法：血雾升腾，斜阳顷刻被染成赭色，远看如同一面翻倒的铁红旗。
