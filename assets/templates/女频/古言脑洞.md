# 古言脑洞（女频）写作模版

英文名：Ancient-Style Brain Holes
成熟度：**A 级** — 已迭代 10 轮，采用第 3 轮（评审分 8.4）

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 古代背景 + 极有创意的设定（穿越、系统、特异能力）
- 女主用横向思维解掉古代场景里的麻烦
- 独特视角撞上时代规矩，笑点由此而来
- 节奏快，喜剧式反转密集
- 感情线次要，女主的目标与成长在前

## 推荐开局钩子

第一个场景就把荒诞设定抖出来

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 开篇钩 | 3 | 9-10分：首千字内即亮出穿书/系统/生死危机等高张力信息，并用独特形式或语气制造记忆点；≤5分：环境描写或日常闲聊占篇幅，主角处境与目标模糊，读者无继续阅读冲动。 |
| 脑洞值 | 3 | 9-10分：金手指、系统、功德商城等设定新奇且与情节深度绑定，同时保留代价或规则；≤5分：设定常见且与剧情脱节，仅作道具罗列或无成本万能。 |
| 爽节奏 | 3 | 9-10分：升级、打脸、翻盘每2-3千字即出现，节奏明快且递进；≤5分：长段铺垫无实质进展，或爽点一次性用尽后陷入拖沓。 |
| 人设彩 | 3 | 9-10分：主要角色登场即以行为+内心声塑出鲜明反差或独特欲望，并能推动情节；≤5分：人物标签单一、依靠旁白硬性夸耀，缺行动支撑。 |
| 逻辑严 | 3 | 9-10分：金手指、权谋、时空规则自洽且前后呼应，细节无硬伤；≤5分：设定随剧情随意变动或角色决策失智。 |
| 对话味 | 2 | 9-10分：对白兼具时代口吻与信息量，性格区隔明显，可独立推动剧情；≤5分：现代语病频繁或大量赘言寒暄，对情节无实质贡献。 |
| 画面感 | 2 | 9-10分：通过感官细节构建时空、动线与情绪，读者易于脑补；≤5分：场景空泛或仅用形容词堆砌，缺乏动态与焦点。 |
| 悬念链 | 2 | 9-10分：每解决一疑问立即抛出更大谜团，形成递进“钩子链”；≤5分：悬念一次性揭秘或长时间空转。 |
| 反转劲 | 2 | 9-10分：关键节点出人意料又合乎情理，制造情绪起伏；≤5分：反转生硬或仅靠信息遮掩，无因果伏笔。 |
| 古韵感 | 1 | 9-10分：遣词、称谓、礼数符合古代语境且与爽文口吻平衡；≤5分：现代网络语/口水句大面积入侵破坏时代感。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "女频/古言脑洞"
```

`--genre` 会把 `assets/prompts/女频/古言脑洞.txt` 追加到默认写作规范之后。
