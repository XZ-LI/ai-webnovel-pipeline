# 游戏体育（女频）写作模版

英文名：Game / Sports Romance (Female)
成熟度：**B 级** — 有语料库反推的评分维度，写作规则未迭代

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 女主在男性主导的电竞或体育领域出头
- 身份隐藏：她其实是传奇选手
- 队内关系、宿敌、冠军线
- 男主与她同级或更强，并且最先认出她的本事
- 线上线下的身份落差推动感情张力

## 推荐开局钩子

她的真实水平意外暴露在男主面前的那一刻

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 钩子强度 | 3 | 开篇是否在300字内建立强烈悬念或颠覆性设定，让读者产生‘必须看下去’的冲动。9-10分：开篇即抛出高信息密度的核心冲突（如重生节点、游戏规则突变、生死倒计时）；5分以下：缓慢铺垫日常，无明确危机或目标。 |
| 规则融合 | 3 | 游戏/体育规则是否自然嵌入叙事而非生硬罗列。9-10分：规则通过角色行动、内心判断或危机应对展现，读者在情节中理解机制；5分以下：大段复制粘贴式公告，打断节奏且无角色反应。 |
| 机缘代价 | 3 | 主角获取优势是否伴随合理风险或道德困境。9-10分：机缘需主动争夺且付出隐性成本（如亲情背叛、时间压迫、道德污点）；5分以下：天降神装无代价，或对手愚蠢送宝。 |
| 品类自觉 | 3 | 是否呼应游戏体育文核心爽点（先知碾压、资源博弈、榜单竞争）。9-10分：章节结尾必提榜单/排名/机缘时效性（如‘离关服还有两小时’）；5分以下：忽略品类标志性元素，写成普通冒险故事。 |
| 节奏张力 | 2 | 章节内是否维持‘目标-障碍-解决’的紧凑循环。9-10分：每500字推进一次小目标达成或危机升级，无冗余描写；5分以下：长时间静态说明或无效对话拖慢进程。 |
| 人设锐度 | 2 | 主角性格是否通过具体行为而非标签展现。9-10分：用反套路选择或极端手段凸显个性（如灌酒阻弟、灵车司机加价）；5分以下：仅用‘杀伐果断’等形容词，行为却优柔寡断。 |
| 世界咬合 | 2 | 游戏机制与现实逻辑是否形成互文。9-10分：游戏规则折射现实痛点（如内测资格=阶级跃迁、公路不可回头=人生无悔）；5分以下：机制与现实割裂，仅为打怪升级服务。 |
| 悬念层级 | 2 | 是否设置多层悬念（即时+中期+长期）。9-10分：单章内含操作悬念（如何偷天赋）、战略悬念（如何压制男主）、世界观悬念（游戏来源）；5分以下：仅依赖单一危机（如怪物追击）。 |
| 升级实感 | 2 | 能力成长是否有可量化路径与资源消耗。9-10分：明确展示属性/物资/技能的获取-消耗-转化链条（如卖紫弓换炼金术）；5分以下：突然变强无过程，或数值膨胀失控。 |
| 反派能见 | 2 | 对立势力是否早期具象化。9-10分：首章出现可恨的具体对手（如经纪人柳争流、弟弟虞寻欢）；5分以下：敌人仅是模糊系统或天灾，缺乏人际冲突支点。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "女频/游戏体育"
```

`--genre` 会把 `assets/prompts/女频/游戏体育.txt` 追加到默认写作规范之后。（本题材的规则层目前只有套路和评分维度，没有迭代出的细则。）
