# 民国言情（女频）写作模版

英文名：Republican Era Romance
成熟度：**B 级** — 有语料库反推的评分维度，写作规则未迭代

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 1910–1940 年代的上海或北平，中西杂处
- 女主受过教育、独立、超前于时代
- 谍战、革命或报人生涯与感情线交织
- 传统与现代之间的三角关系
- 时代细节丰盛：旗袍、茶楼、租界、军阀政治

## 推荐开局钩子

女主第一次与敌对阵营的男人产生危险纠缠

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 钩子 | 3 | 评估开篇三百字内是否迅速抛出危险-利益-情感三重刺激。
9-10分：读者三秒即知女主所处险境或利益赌注
5分以下：仅日常起居、天气描写，无悬而未决的问题，读者可随时放下。 |
| 矛盾 | 3 | 衡量主线冲突是否尖锐且与民国特定权力结构挂钩（军阀、政商、家族）。
9-10分：私情与政局双线冲突清晰，角色不可回避
5分以下：冲突模糊或只停留在口头互怼，与时代权力脱节。 |
| 人设 | 3 | 角色是否以行为而非独白立体呈现，并带有民国独特阶层印记（少帅、名伶、留洋千金）。
9-10分：三句对白即可分辨出性格与立场。
5分以下：只有浮夸标签或脸谱化形容词。 |
| 民味 | 3 | 时代氛围与现实规则（租界、军政府、洋行、银元物价）是否融入情节而非旁白科普。
9-10分：读者通过动作即可感知时代机制。
5分以下：穿越或玄幻设定喧宾夺主，削弱民国质感。 |
| 节奏 | 2 | 看场景推进与信息释放的张弛。 
9-10分：动作-对话-背景三线交替，无长段说明书。
5分以下：连篇回忆或设定灌输，致使张力熄火。 |
| 场景 | 2 | 视觉、嗅觉、服饰、建筑是否共同营造民国质感。
9-10分：细节可画，且与情绪互为呼应。
5分以下：家装颜色+家具型号堆砌，缺乏时代特征。 |
| 对话 | 2 | 对白是否口吻分明并含时代腔调（本帮话、洋泾浜、军中术语）。
9-10分：语言能区分长辈/军人/舞女，且推动剧情。
5分以下：现代口水或生硬信息抛售。 |
| 悬念 | 2 | 章节末是否留下悬而未解的问题或危机。
9-10分：读者产生“下一页痛点”，如性命、婚约、政变。
5分以下：情节收口平，无未竟之事。 |
| 情感 | 2 | 情绪渗透是否自然，能否引发读者同理（家国、亲情、爱情多维）。
9-10分：情感通过互动或反应传递而非喊口号。
5分以下：只列惨案或喊爽点，缺乏人物内化感受。 |
| 翻转 | 2 | 是否出现出人意料却合乎逻辑的局势或立场逆转。
9-10分：已有认知被瞬间改写并推动下一冲突。
5分以下：情节线性、预测即所得。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "女频/民国言情"
```

`--genre` 会把 `assets/prompts/女频/民国言情.txt` 追加到默认写作规范之后。（本题材的规则层目前只有套路和评分维度，没有迭代出的细则。）
