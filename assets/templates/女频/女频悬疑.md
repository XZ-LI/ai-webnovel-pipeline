# 女频悬疑（女频）写作模版

英文名：Female Mystery / Thriller
成熟度：**B 级** — 有语料库反推的评分维度，写作规则未迭代

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 女主查办灵异案件或刑事案件
- 她的专业背景（法医、心理、通灵）推着情节走
- 感情在共担危险与彼此敬重中生长
- 心理层面的紧张与阴郁氛围
- 反转会把读者此前的认知整个推翻

## 推荐开局钩子

女主第一次遇上无法用常理解释的案子

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 钩子强度 | 3 | 开篇是否在300字内建立强烈悬念或冲突，引发读者继续阅读的冲动。9-10分：首段即抛出高能设定、身份反转或生死危机；5分以下：平铺直叙背景介绍，无即时张力。 |
| 人设立体 | 3 | 主角是否具备鲜明反差特质与内在矛盾，避免扁平化。9-10分：角色有生理/心理弱点+超常能力+道德模糊性；5分以下：纯靠金手指碾压，无真实困境或情感层次。 |
| 悬念密度 | 3 | 每千字内埋设的有效悬念数量及质量。9-10分：每章至少1个强悬念（如身份暴露风险、关键物证缺失、时间倒计时）；5分以下：依赖单一主线悬念，中间无新疑问激发。 |
| 逻辑闭环 | 3 | 案件推理是否符合刑侦/法医/心理等专业逻辑。9-10分：破案依据有科学支撑，漏洞可解释；5分以下：依赖巧合或主角直觉，无视现实规则。 |
| 反转设计 | 2 | 情节转折是否合理且具冲击力。9-10分：反转基于前文伏笔，颠覆读者预期但逻辑自洽；5分以下：突兀转折无铺垫，或为反转而反转。 |
| 节奏把控 | 2 | 叙事快慢是否匹配悬疑需求。9-10分：关键场景（如对峙、发现尸体）用细节慢镜头，过渡段落快速推进；5分以下：全程匀速叙述，高潮无聚焦，或冗长描写拖沓。 |
| 对话张力 | 2 | 人物对白是否推动剧情或揭示性格。9-10分：对话含潜台词、权力博弈或信息差；5分以下：纯功能交代（如‘你好我是警察’）或情绪直给（如‘我恨你！’）。 |
| 情感锚点 | 2 | 是否建立读者对角色命运的情感投入。9-10分：通过脆弱时刻（如身体痛苦、道德挣扎）引发共情；5分以下：角色冷漠疏离，无情感支点。 |
| 世界观融合 | 2 | 超现实元素（如灵异、特殊体质）是否自然嵌入现实逻辑。9-10分：设定有规则、代价与限制，并影响剧情走向；5分以下：能力随意开关，无约束机制。 |
| 感官沉浸 | 1 | 是否通过视听嗅触味构建临场感。9-10分：多感官细节服务于氛围营造（如血腥味、枪械触感、灯光阴影）；5分以下：仅视觉描述，或堆砌无关环境词。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "女频/女频悬疑"
```

`--genre` 会把 `assets/prompts/女频/女频悬疑.txt` 追加到默认写作规范之后。（本题材的规则层目前只有套路和评分维度，没有迭代出的细则。）
