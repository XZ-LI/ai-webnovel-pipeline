# 玄幻言情（女频）写作模版

英文名：Female Xuanhuan Romance
成熟度：**A 级** — 已迭代 15 轮，采用第 8 轮（评审分 8.2）

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 女主穿书成炮灰或反派配角
- 她知道原作剧情，用先知避开自己的死亡线
- 拒恋爱脑：不肯给男主的爱情戏当工具
- 反套路喜剧——她“不按人设走”，把所有人都整懵了
- 隐藏实力逐步显形，对看轻她的人一路打脸
- 多个爱慕者前后出现，而她并不主动追谁
- 修仙或武道体系，境界划分清楚
- 可靠的姐妹情或忠诚的配角团

## 推荐开局钩子

女主意识到自己穿了书、并认出这是哪本书的那一刻

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 开钩 | 3 | 首章或每章前数百字的抓人程度。高分要求迅速抛出独特设定或冲突（如穿书+苟命、系统倒计时），信息密度高且情绪直接触发读者好奇；低分为大段世界背景或日常碎叙，缺乏事件引爆点。 |
| 角色 | 3 | 人物鲜活度与辨识度。高分要求性格、语言、行为高度一致且有反差萌（如病美人却毒舌、疯批师兄却宠溺）；低分则人设标签化，或全员同一种嘴炮风格。 |
| 情张 | 3 | 情感张力与共鸣程度。高分作品在爽文外核下嵌入救赎、反噬、师门亲情等多线情绪，让甜虐反差显著；低分仅靠堆叠土味情话或无来由的哭喊。 |
| 设定 | 3 | 世界观与言情线的融合度。高分要求灵根、宗门、系统、命数等设定自洽且直接驱动情节与情感；低分为大量设定讲解却对主线无实质作用或频繁打破自身规则。 |
| 节奏 | 2 | 剧情推进与停顿的张弛掌控。高分章节能在3000字左右完成事件-反转-小结尾，笑点、爽点与情感点交替；低分则是长篇对话或战斗拖沓，或者连续打脸没有喘息。 |
| 画面 | 2 | 场景描写的可视化与代入感。高分文本以少量生动细节构建宗门、灵植、法器等视觉与感官层次；低分则堆叠华丽形容却无法形成具体影像。 |
| 悬念 | 2 | 伏笔与留白的吸引力。高分章节在结尾或中段设置疑问（隐藏身世、系统惩罚、师兄黑化），同时给出可期待的解决路径；低分要么无悬念，要么强行卖关子长期不兑现。 |
| 对话 | 1 | 语言是否贴合身份且自然流畅。高分表现为古言基调中穿插现代梗而不违和，信息量与情绪并存；低分则台词机械、角色口吻混同或尬古风。 |
| 章差 | 1 | 章节之间的新鲜度与差异度。高分作品每章都提供新场景/角色/任务或情绪转折，保证阅读黏性；低分则模板化重复（连续三章都是打脸抢丹）。 |
| 外描 | 1 | 外形描写与人物气质的匹配度。高分为外貌细节服务于性格、修为或剧情走向；低分则无止境重复‘皓齿朱唇’式模板美或完全忽略外貌带来的差异。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "女频/玄幻言情"
```

`--genre` 会把 `assets/prompts/女频/玄幻言情.txt` 追加到默认写作规范之后。
