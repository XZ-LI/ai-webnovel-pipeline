# 古风世情（女频）写作模版

英文名：Ancient-Style Slice of Life Romance
成熟度：**B 级** — 有语料库反推的评分维度，写作规则未迭代

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 古代中国背景，风俗、饮食、服饰写得细
- 带现代思维的女主在礼法社会里周旋
- 以经商或手艺立身，换取独立
- 慢热感情线，男主尊重她的自主
- 宗族政治、算计的亲戚、家产之争

## 推荐开局钩子

女主第一次正面违抗某条礼法约束

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 钩子强度 | 3 | 开篇是否在300字内建立强烈悬念或冲突，引发读者继续阅读的冲动。9-10分：首段即抛出颠覆性设定、生死危机或身份反转；5分以下：平铺直叙背景介绍，无即时张力。 |
| 人设锐度 | 3 | 主角是否具备鲜明、反套路的性格标签与行为逻辑。9-10分：角色言行自带记忆点，性格与处境形成戏剧张力；5分以下：人设模糊或沦为工具人，行为动机不清。 |
| 世情肌理 | 2 | 是否通过细节自然呈现古代社会结构、阶层规则与生活逻辑。9-10分：衣食住行、称谓礼仪、经济关系等细节精准且服务于剧情；5分以下：时代背景空洞，或出现现代思维硬伤。 |
| 权谋密度 | 2 | 政治/家族斗争是否具备信息差、利益链与策略性。9-10分：多方势力博弈有隐藏线索，角色行动基于情报与算计；5分以下：矛盾靠巧合或降智推动，无真实权力逻辑。 |
| 反转节奏 | 2 | 情节转折是否符合‘铺垫-爆发-余波’结构，且频率适中。9-10分：每章有小型反转，关键章有颠覆性转折，节奏张弛有度；5分以下：平铺直叙无起伏，或反转突兀无伏笔。 |
| 对话锋芒 | 2 | 台词是否兼具古风韵味与角色个性，推动剧情或揭示关系。9-10分：每句对话有潜台词，体现身份差、情绪张力或信息交锋；5分以下：对话冗长注水，或沦为现代口语翻译。 |
| 情感锚点 | 2 | 是否建立让读者共情的核心情感诉求（如守护、复仇、尊严）。9-10分：主角动机具象可感（如护玉镯、救家人），情感贯穿行动；5分以下：目标空泛（如‘变强’‘逆袭’）无情感支点。 |
| 机缘代价 | 2 | 主角获得助力是否伴随明确风险或道德困境。9-10分：金手指/盟友有使用限制或潜在反噬；5分以下：外挂无代价，成功轻而易举。 |
| 群像厚度 | 1 | 配角是否具备独立行为逻辑与功能价值。9-10分：配角推动主线或映照主角，有简练但鲜明的刻画；5分以下：配角纯为衬托主角存在，面目模糊。 |
| 文韵质感 | 1 | 语言是否融合古典语感与现代流畅性。9-10分：用词考究但不晦涩，比喻新颖贴合世界观；5分以下：堆砌辞藻或过度白话，破坏沉浸感。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "女频/古风世情"
```

`--genre` 会把 `assets/prompts/女频/古风世情.txt` 追加到默认写作规范之后。（本题材的规则层目前只有套路和评分维度，没有迭代出的细则。）
