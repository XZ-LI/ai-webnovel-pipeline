# 青春甜宠（女频）写作模版

英文名：Youth Sweet Romance
成熟度：**B 级** — 有语料库反推的评分维度，写作规则未迭代

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 校园或刚入社会的背景，感情干净清甜
- 女主明亮温暖，男主冷淡却专一
- 误会很快澄清——低虐、高糖
- 生活流的暖意：吃食、季节、功课、友情
- 初恋的纯度与生活小坎的对照

## 推荐开局钩子

两人之间第一个说不清的心动瞬间

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 钩子强度 | 3 | 开篇是否在300字内迅速建立情感张力或悬念，引发读者继续阅读的冲动。9-10分：首段即呈现命运感、生死危机、身份错位或强烈反差；5分以下：平铺直叙日常，无情绪爆点或信息钩子。 |
| 人设反差 | 3 | 主角是否具备鲜明且互补的性格/身份反差（如乖巧×痞坏、社恐×拽哥、学霸×不良），形成天然戏剧张力。9-10分：反差具象化于外貌、行为、台词中，且推动互动；5分以下：角色标签化，缺乏细节支撑或互动逻辑。 |
| 甜宠节奏 | 3 | 亲密互动是否在前4章内高频出现且层层递进（眼神→对话→肢体→保护）。9-10分：每章至少1次有效糖点（如挡灾、护短、吃醋、暧昧），情绪升温自然；5分以下：感情线拖沓，互动仅限对视或单向暗恋。 |
| 对话自然 | 2 | 角色台词是否贴合身份、年龄与性格，避免书面化或强行金句。9-10分：口语化、带个性烙印（如痞气、社恐结巴、毒舌），推动剧情；5分以下：对话像旁白解说，或堆砌网络热梗无角色辨识度。 |
| 画面感强 | 2 | 场景与人物描写是否具电影镜头感，能激发读者视觉想象。9-10分：善用色彩、光影、动作细节（如‘浅紫裙子’‘银发少年三步上篮’‘锁骨挂银链’）；5分以下：仅用‘漂亮’‘帅气’等抽象词，无具体意象。 |
| 悬念设计 | 2 | 是否埋设短期（章节内）或中期（3-5章）悬念驱动追读。9-10分：每章结尾留钩（如身份秘密、病情恶化、重逢冲击）；5分以下：章节结束于平淡日常，无信息增量或情绪转折。 |
| 情感真实 | 2 | 角色情绪反应是否符合情境逻辑，避免强行虐或突兀甜。9-10分：情绪有铺垫（如病痛中的脆弱、社恐被吓后的颤抖）、有层次；5分以下：情绪跳跃（如秒爱、无理由原谅），或为虐而虐。 |
| 世界观融合 | 2 | 特殊设定（重生、偶像身份、疾病）是否自然融入校园日常。9-10分：设定推动情节（如重生避豪门、偶像隐退引秘密）；5分以下：设定与主线割裂，像硬贴标签。 |
| 节奏把控 | 2 | 叙事是否张弛有度，避免冗长铺垫或信息过载。9-10分：开篇3章内完成‘相遇→冲突→初步羁绊’，信息密度适中；5分以下：第一章大段背景说明，或连续多章无进展。 |
| 配角功能 | 1 | 配角是否有效服务主线（助攻/制造冲突/衬托主角）。9-10分：配角有记忆点且推动剧情（如杨世昆传话、云朵引出回忆）；5分以下：配角纯工具人，台词重复或行为无意义。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "女频/青春甜宠"
```

`--genre` 会把 `assets/prompts/女频/青春甜宠.txt` 追加到默认写作规范之后。（本题材的规则层目前只有套路和评分维度，没有迭代出的细则。）
