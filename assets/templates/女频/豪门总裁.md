# 豪门总裁（女频）写作模版

英文名：Wealthy CEO Romance
成熟度：**B 级** — 有语料库反推的评分维度，写作规则未迭代

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 契约婚姻、意外纠缠，或与总裁的宿敌转情人
- 女主经济独立，拒绝被包养的位置
- 家族生意的暗斗、继承权争夺、商战
- 男主外冷内伤，而伤口只有她碰得到
- 奢华场景与真实情绪脆弱面的对照

## 推荐开局钩子

女主与总裁之间第一次出乎意料的力量反转

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 钩子强度 | 3 | 开篇是否在300字内建立强烈情绪冲突或身份反差，引发读者追读欲。9-10分：首段即呈现生死、尊严、情感等高危情境；5分以下：平铺直叙日常，无紧迫感或悬念。 |
| 人设锐度 | 3 | 主角是否具备鲜明、极致且符合豪门语境的性格标签（如疯批、隐忍、毒舌）。9-10分：性格通过动作/对话自然外显，有记忆点；5分以下：标签堆砌但行为矛盾，或沦为工具人。 |
| 阶级张力 | 3 | 是否清晰展现豪门内部的权力层级与资源不对等（如话事人、太子爷、联姻筹码）。9-10分：通过细节（称谓、空间、规矩）自然呈现阶级鸿沟；5分以下：仅靠台词喊‘他是首富’，无实质落差描写。 |
| 情感烈度 | 2 | 亲密互动是否兼具危险性与诱惑力，体现‘强强对抗中的荷尔蒙’。9-10分：肢体/语言充满控制与反抗的张力；5分以下：甜腻无冲突或纯暴力无情感逻辑。 |
| 节奏密度 | 2 | 每千字是否包含至少1个情节爆点（冲突/反转/秘密揭露）。9-10分：信息密集，无冗余描写；5分以下：大段环境/心理独白拖慢叙事。 |
| 台词锋芒 | 2 | 对话是否简短有力，体现人物立场与关系张力。9-10分：每句台词推动剧情或揭示性格；5分以下：口水话堆砌，如‘你好吗’‘我很好’式无效交流。 |
| 悬念嵌套 | 2 | 是否在章节结尾埋设多层悬念（短期+长期）。9-10分：结尾同时抛出即时危机与世界观谜题；5分以下：悬念单一或强行中断。 |
| 关系颠覆 | 2 | 是否快速打破表面关系（如兄妹/仇敌/契约），揭示隐藏纽带。9-10分：前三章内完成关系认知反转；5分以下：关系进展缓慢或逻辑断裂。 |
| 感官沉浸 | 1 | 是否通过五感描写（尤其触觉/嗅觉）强化场景真实感。9-10分：关键场景有独特感官印记；5分以下：仅视觉描写，氛围扁平。 |
| 代价真实 | 1 | 角色选择是否伴随切实损失（尊严/金钱/亲情），避免龙傲天式零成本胜利。9-10分：每次行动都有明确代价；5分以下：主角光环过强，冲突轻易化解。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "女频/豪门总裁"
```

`--genre` 会把 `assets/prompts/女频/豪门总裁.txt` 追加到默认写作规范之后。（本题材的规则层目前只有套路和评分维度，没有迭代出的细则。）
