# 种田（女频）写作模版

英文名：Farming / Homesteading Romance
成熟度：**B 级** — 有语料库反推的评分维度，写作规则未迭代

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 女主靠种地、做饭或手艺把日子重新立起来
- 随身空间或作弊道具加速生产
- 乡里人情的暖，和被慢慢接纳的过程
- 男主起初冷淡，被她踏实的本事折服
- 感情在一起干活、过日子里慢慢熬出来

## 推荐开局钩子

女主第一次收成或做出的东西，惊到了周围所有人

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 开篇钩子 | 3 | 首章开头是否在300字内建立强烈代入感或危机感。9-10分：迅速呈现生死/生存压力、身份错位或独特设定，引发读者‘必须看下去’的冲动；5分以下：平铺直叙背景、大段说明或无冲突日常。 |
| 种田逻辑 | 3 | 农事/经营行为是否符合时代技术条件且具可操作性。9-10分：细节真实（如作物时令、工具使用、成本核算），体现‘劳动创造价值’；5分以下：凭空变出物资、无视季节规律或用现代知识碾压古人而不解释。 |
| 危机代价 | 3 | 主角获取资源是否伴随真实风险与损失。9-10分：每次收获需付出体力/健康/人情代价（如冻伤、被讹诈）；5分以下：机缘随手可得，失败无后果或反派降智送宝。 |
| 人设反差 | 2 | 主角身份与能力/处境是否形成有效张力。9-10分：穿越者利用现代知识但受限于古代条件（如无系统、无空间），需真实挣扎；5分以下：金手指过大掩盖人物成长，或反派扁平化只为衬托主角。 |
| 乡土质感 | 2 | 是否呈现真实的乡村社会关系与生活肌理。9-10分：展现宗族矛盾、邻里互助、生产协作等细节；5分以下：村庄如游戏副本，NPC功能单一或对话过于现代化。 |
| 节奏把控 | 2 | 章节内信息密度与事件推进是否匹配种田文慢热特性。9-10分：用具体劳作（如开荒、制药）填充时间，危机与日常交替；5分以下：跳过关键积累过程直接致富，或大段无意义对话拖沓。 |
| 世界自洽 | 2 | 超自然元素（如有）是否与种田逻辑融合。9-10分：灵泉/空间等设定有明确限制（如每日产量、升级条件）；5分以下：金手指无规则，随剧情需要随意扩大功能。 |
| 去爽文化 | 2 | 是否避免男频式打脸套路，聚焦生存本身。9-10分：冲突源于自然灾害/制度压迫而非个人恩怨，解决靠合作而非碾压；5分以下：频繁出现‘虐渣’‘打脸’情节，将种田异化为复仇工具。 |
| 对话土味 | 1 | 角色语言是否符合身份与时代语境。9-10分：农妇用‘屁大的村子’‘拼了’等粗粝口语，孩童说话简短直白；5分以下：古人说网络流行语或长篇大论讲道理。 |
| 情感锚点 | 1 | 是否建立读者关心的具体人际关系。9-10分：通过共同劳作（如背柴上山）、食物分享（如分鸡蛋）等细节积累羁绊；5分以下：亲情/爱情全靠设定说明（如‘狼群宠成公主’但无互动）。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "女频/种田"
```

`--genre` 会把 `assets/prompts/女频/种田.txt` 追加到默认写作规范之后。（本题材的规则层目前只有套路和评分维度，没有迭代出的细则。）
