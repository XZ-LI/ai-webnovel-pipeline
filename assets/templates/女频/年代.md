# 年代（女频）写作模版

英文名：Republican / Mid-Century Era Romance
成熟度：**B 级** — 有语料库反推的评分维度，写作规则未迭代

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 1930–1980 年代中国，时代约束还原得准
- 女主在婚姻、工作与社会变动之间腾挪
- 现代意识被移植进物质匮乏的年代
- 战争、改革或运动作为个人故事的底色
- 感情在共同熬过来和观念成长中建立

## 推荐开局钩子

女主第一次做出不符合那个年代对女性期待的事

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 钩子强度 | 3 | 开篇是否在300字内建立强烈冲突或悬念，让读者产生‘必须看下去’的冲动。9-10分：首段即呈现生死抉择、身份反转或时代压迫感；5分以下：平铺直叙日常，无紧迫感或情绪张力。 |
| 时代质感 | 3 | 是否通过细节真实还原特定年代的社会肌理（如粮票、工分、大喇叭、成分论）。9-10分：器物、制度、语言、空间布局高度契合历史语境；5分以下：时代仅作背景板，充斥现代思维或常识错误（如60年代出现超市）。 |
| 人设立骨 | 3 | 主角是否在首章展现鲜明性格棱角与行动逻辑。9-10分：言行体现独特价值观（如痞气、刚烈、算计），拒绝扁平化；5分以下：被动反应、情绪模糊或行为动机不清。 |
| 矛盾锐度 | 3 | 核心冲突是否尖锐且具年代特异性（如成分压迫、换亲、下放）。9-10分：矛盾直指时代痛点（如烈士孤女被夺抚恤金）；5分以下：冲突泛化为普通家庭纠纷，无历史纵深感。 |
| 逆袭路径 | 3 | 是否清晰展示主角破局手段与时代规则互动。9-10分：利用年代特有资源/漏洞（如工分制、黑市、军籍）设计合理翻身策略；5分以下：依赖金手指或巧合，无现实逻辑支撑。 |
| 节奏张力 | 2 | 情节推进是否紧凑，每500字至少有一个情绪爆点或转折。9-10分：对话交锋密集、行动链环环相扣（如退婚→回家→对峙→父亲发怒）；5分以下：大段静态描写或琐碎日常拖沓主线。 |
| 情感真实 | 2 | 情绪反应是否符合人物处境与年代心理逻辑。9-10分：悲喜有时代烙印（如见主席像怕震落、对粮票的执念）；5分以下：情绪现代化（如轻易原谅仇人）或过度煽情失真。 |
| 台词锋芒 | 2 | 对话是否兼具时代特征与人物个性，推动剧情而非注水。9-10分：每句台词暴露立场/关系（如‘资本家狗崽子’显政治话语）；5分以下：对话冗长无信息量或现代口语泛滥。 |
| 命运紧迫 | 2 | 是否营造倒计时式危机感（如下乡截止、偷渡窗口、婚期逼近）。9-10分：明确时间锁（如‘三天后抬人’）驱动主角行动；5分以下：危机模糊，主角可无限拖延。 |
| 群像鲜活 | 1 | 配角是否具独立动机与时代典型性。9-10分：配角行为反映阶层立场（如混混讲义气、干部重面子）；5分以下：配角纯工具人，言行只为衬托主角。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "女频/年代"
```

`--genre` 会把 `assets/prompts/女频/年代.txt` 追加到默认写作规范之后。（本题材的规则层目前只有套路和评分维度，没有迭代出的细则。）
