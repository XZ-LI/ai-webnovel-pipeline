# 宫斗宅斗（女频）写作模版

英文名：Palace/Household Political Intrigue
成熟度：**B 级** — 有语料库反推的评分维度，写作规则未迭代

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 女主在后宫或宗族的血腥政治里求存
- 结盟与情报是她的主要武器
- 看似盟友的敌人，和戏剧性的背叛
- 她的心智对上男主的权势
- 赌注是活命，不只是爱情——每个决定都被这一点推着走

## 推荐开局钩子

女主用意料之外的机敏，从第一个政治陷阱里活了下来

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 钩子强度 | 3 | 开篇是否在300字内建立强烈悬念或情感冲击，引发读者继续阅读欲望。9-10分：首段即呈现生死、背叛、重生等高张力情境；5分以下：平铺直叙背景介绍，无情绪爆点。 |
| 人设立骨 | 3 | 主角是否在首章展现鲜明性格、处境与动机。9-10分：通过动作、对话、细节立体呈现其坚韧/聪慧/隐忍等特质；5分以下：主角被动反应，无主动选择或内心逻辑。 |
| 宅斗张力 | 3 | 是否在家庭/府邸内部构建清晰权力结构与潜在冲突。9-10分：通过称谓、动线、器物、礼仪等细节自然呈现嫡庶、主仆、婆媳等矛盾；5分以下：人物关系模糊，冲突靠台词直说而非情境体现。 |
| 品类调性 | 3 | 是否契合宫斗宅斗核心爽感（智斗＞武斗，隐忍＞直刚，制度碾压＞个人勇武）。9-10分：主角以礼法、人心、资源为武器破局；5分以下：依赖金手指、突然发疯或物理暴力解决矛盾。 |
| 反转密度 | 2 | 章节内是否包含至少一个有效剧情反转（非单纯打脸）。9-10分：反转推动主线、改变人物关系或认知；5分以下：无反转或仅为情绪宣泄式'打脸'。 |
| 礼制真实 | 2 | 是否准确运用古代礼法、称谓、空间规制增强可信度。9-10分：晨昏定省、角门/正门、诰命称谓等细节符合历史逻辑；5分以下：称谓混乱（如乱用'夫人''小姐'）、空间无等级（如妾可随意进主院）。 |
| 情感层次 | 2 | 主角情绪是否复杂且有递进（非单一愤怒/悲伤）。9-10分：展现隐忍中的刺痛、温柔下的决绝等矛盾情感；5分以下：情绪扁平，全靠台词喊出。 |
| 节奏控制 | 2 | 信息释放是否张弛有度，避免堆砌或拖沓。9-10分：关键信息（如重生、替身、阴谋）在冲突高潮点释放；5分以下：大段回忆插叙打断当前戏剧行动。 |
| 伏笔埋设 | 2 | 是否在细节中预埋后续关键线索（物品、对话、习惯）。9-10分：看似闲笔实为重要机缘/证据；5分以下：无伏笔或过于直白（如'此物日后必有用'）。 |
| 配角功能 | 1 | 次要人物是否承担明确叙事作用（激化矛盾/提供情报/映照主角）。9-10分：丫鬟、嬷嬷等言行推动剧情或揭示规则；5分以下：配角仅为情绪附庸，无独立动机。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "女频/宫斗宅斗"
```

`--genre` 会把 `assets/prompts/女频/宫斗宅斗.txt` 追加到默认写作规范之后。（本题材的规则层目前只有套路和评分维度，没有迭代出的细则。）
