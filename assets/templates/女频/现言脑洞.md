# 现言脑洞（女频）写作模版

英文名：Modern Romance Brain Holes
成熟度：**B 级** — 有语料库反推的评分维度，写作规则未迭代

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 现代背景 + 非常规设定（灵异、系统、隐世界）
- 女主嘴利，解决问题的路子不走寻常
- 职场或社会讽刺织进感情线
- 男主起初敌对或冷漠，渐渐被她拿下
- 喜剧节奏快，但情绪账要还

## 推荐开局钩子

女主与男主（或与系统）那场很不寻常的初遇

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 钩子强度 | 3 | 开篇是否在300字内制造强烈悬念、冲突或反常情境，引发读者继续阅读的冲动。9-10分：开篇即高能，用荒诞、危机或身份错位瞬间抓住注意力；5分以下：平铺直叙背景设定，无即时冲突或情绪张力。 |
| 脑洞新颖 | 3 | 设定是否在现言框架下融合超现实元素（穿书、玄学、异能等）并形成独特逻辑闭环。9-10分：脑洞与现实逻辑自洽，且带来新鲜叙事可能；5分以下：套用烂俗设定（如普通重生复仇）无新意，或设定与剧情脱节。 |
| 人设立体 | 3 | 主角是否通过言行细节展现复杂性格（如表面傻白甜实则心机），而非标签化。9-10分：角色有反差、有动机、有成长伏笔；5分以下：人设扁平，全靠旁白说明‘她很聪明/狠毒’而无行为佐证。 |
| 节奏张力 | 2 | 章节内是否保持高频事件推进，避免冗长说明。9-10分：每300-500字有新转折或冲突升级；5分以下：大段背景解说、心理独白或静态描写拖慢节奏。 |
| 对话鲜活 | 2 | 对话是否符合角色身份且推动剧情，而非信息堆砌。9-10分：台词有个性、带潜台词、引发行动；5分以下：对话如说明书，只为交代设定或重复已知信息。 |
| 悬念设计 | 2 | 是否在章节结尾或关键节点埋设待解谜题。9-10分：悬念与主线强相关，激发读者对后续因果的好奇；5分以下：悬念模糊（如‘她感到不安’）或与主线无关。 |
| 世界观融 | 2 | 超现实设定是否自然嵌入现代背景，不显突兀。9-10分：用日常细节承载奇幻元素（如玄学摆摊、魔法学院停机坪）；5分以下：设定强行插入，与现实逻辑割裂。 |
| 反转密度 | 2 | 章节内是否包含至少一次合理但意外的情节转向。9-10分：反转基于伏笔，颠覆读者预期；5分以下：剧情线性发展，无波折或反转生硬。 |
| 情绪感染 | 1 | 能否通过细节引发读者共情（如饥饿、恐惧、荒诞喜感）。9-10分：用身体感受或黑色幽默传递情绪；5分以下：情绪靠直述（如‘她很害怕’）而无具象描写。 |
| 系统辅助 | 1 | 若有金手指/系统，是否服务于剧情而非替代思考。9-10分：系统提供有限帮助，主角仍需自主破局；5分以下：系统万能，主角躺赢，削弱戏剧性。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "女频/现言脑洞"
```

`--genre` 会把 `assets/prompts/女频/现言脑洞.txt` 追加到默认写作规范之后。（本题材的规则层目前只有套路和评分维度，没有迭代出的细则。）
