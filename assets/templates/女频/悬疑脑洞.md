# 悬疑脑洞（女频）写作模版

英文名：Mystery Brain Holes (Female)
成熟度：**B 级** — 有语料库反推的评分维度，写作规则未迭代

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 女主有特殊的推理能力或灵异体质
- 悬疑主线与感情线咬合——一起破案一起走近
- 现实并不可靠：所见未必所是
- 黑色幽默与荒诞逻辑
- 可做双男主：两种性格都被她吸引

## 推荐开局钩子

女主遇上的第一桩不可能之谜

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 钩子强度 | 3 | 开篇是否在300字内建立强烈悬念或反常情境，引发读者继续阅读的冲动。9-10分：开篇即呈现超现实异常、身份错位或生死危机；5分以下：平铺直叙日常，无异常信号或延迟揭示核心设定。 |
| 规则显影 | 3 | 是否清晰、巧妙地呈现副本/世界的核心规则，且规则本身具备逻辑自洽与致命张力。9-10分：规则通过角色互动自然浮现，兼具诡异感与可操作性；5分以下：规则模糊不清、纯靠旁白说明，或与剧情脱节。 |
| 世界观缝合 | 3 | 脑洞设定（如无限流、系统、穿越）是否与悬疑场景有机融合，而非生硬套用模板。9-10分：副本机制与角色背景互为因果，如KPOP规则呼应偶像失格恐惧；5分以下：仅贴标签（“这是规则怪谈”），机制与剧情无深层关联。 |
| 人设反差 | 2 | 主角是否具备表面形象与内在能力的强烈反差，形成“扮猪吃虎”或“疯批美人”等悬疑张力。9-10分：外表柔弱/疯癫但行为精准狠辣，反差服务于破局；5分以下：人设扁平，言行一致无层次，或反差仅为噱头无功能。 |
| 节奏张弛 | 2 | 章节内是否交替安排紧张危机与信息缓冲，避免持续高压或冗长铺垫。9-10分：每800-1200字设置一次小型反转或规则验证，节奏如心跳般起伏；5分以下：全程对话无推进，或连续惊吓无喘息导致麻木。 |
| 悬念嵌套 | 2 | 是否在解决当前危机的同时埋设更高阶谜题，形成“解一现二”的悬疑结构。9-10分：每章结尾抛出新疑问（如沈迹能镇压鬼影的能力来源）；5分以下：问题线性解决，无遗留线索或后续牵引。 |
| 对话机锋 | 2 | 角色对话是否暗含试探、误导或规则验证，而非单纯信息传递。9-10分：每句对白兼具表层情绪与深层博弈，如时镜诱使喜婆暴露规则；5分以下：对话仅为交代背景或情绪宣泄，无策略性。 |
| 代价显性 | 2 | 角色获取信息或能力是否伴随明确风险或资源消耗，强化生存压力。9-10分：每次行动均有失败惩罚（如触碰规则即死），资源（时间、体力、道具）有限；5分以下：主角无成本试错，或系统无限兜底。 |
| 脑洞闭环 | 2 | 章节内是否实现“设定-验证-应用”小闭环，证明世界观自洽。9-10分：主角利用本章发现的规则/能力解决本章危机；5分以下：规则仅被提及未被使用，或破局依赖外部救场。 |
| 感官浸染 | 1 | 是否通过多感官描写（视觉扭曲、声音异变、触觉异常）构建沉浸式恐怖氛围。9-10分：异常现象调动至少三种感官，且符合场景逻辑（如医院消毒水混血腥）；5分以下：仅依赖“黑影”“尖叫”等抽象词汇。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "女频/悬疑脑洞"
```

`--genre` 会把 `assets/prompts/女频/悬疑脑洞.txt` 追加到默认写作规范之后。（本题材的规则层目前只有套路和评分维度，没有迭代出的细则。）
