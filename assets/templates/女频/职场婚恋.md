# 职场婚恋（女频）写作模版

英文名：Workplace Marriage Romance
成熟度：**B 级** — 有语料库反推的评分维度，写作规则未迭代

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 现代职场背景，一对已婚或即将结婚的人
- 事业心与关系之间的张力
- 隐婚或身份在同事面前曝光
- 女主的专业价值独立于伴侣得到承认
- 居家的暖和职场的争形成对照

## 推荐开局钩子

上班第一天，发现要和那个有秘密关联的人共事

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 钩子强度 | 3 | 开篇是否在300字内建立强烈情绪冲突或身份反差，引发读者继续阅读的冲动。9-10分：开篇即呈现高张力场景（如羞辱、危机、重逢），主角反应鲜明有力；5分以下：平铺直叙背景介绍，无即时冲突或情绪爆点。 |
| 人设立体 | 3 | 主角是否通过具体行为、细节或对话展现独特性格与职业特质。9-10分：角色言行符合职场身份且具辨识度（如助听器、翻译稿、系统维护），有记忆点；5分以下：标签化描写（如‘温柔’‘霸道’无支撑），职业仅作背景板。 |
| 职场融合 | 3 | 婚恋主线是否自然嵌入真实职场情境，而非仅作背景。9-10分：职场规则、专业细节推动情节（如系统IP限制、翻译履历、教师困境）；5分以下：职场仅用于交代身份，情节与工作无关（如突然被总裁救下）。 |
| 情感节奏 | 2 | 亲密关系推进是否符合‘职场婚恋’特有的克制与试探节奏。9-10分：情感升温依托职场互动（如送伞、远程操作、捉奸抉择），有留白与张力；5分以下：感情发展突兀（如闪婚无铺垫），或过度依赖狗血误会。 |
| 对话质感 | 2 | 对话是否符合人物身份、职业语境且推动剧情。9-10分：语言风格差异化（如外交官简练、教师理性、总裁低沉），含潜台词；5分以下：对话冗长说教，或充斥不自然英文/网络语。 |
| 悬念设计 | 2 | 章节结尾是否埋设与职场或情感相关的新疑问。9-10分：悬念源于角色选择或职场危机（如‘定金都收了’‘系统能否撑住’）；5分以下：悬念靠外部威胁（如跟踪者）或强行中断对话。 |
| 细节真实 | 2 | 职场与生活细节是否经得起推敲。9-10分：专业术语准确（如心外科、德语翻译、发改委项目科），生活逻辑合理（如租房预算、电动车避雨）；5分以下：细节错误或悬浮（如农村总裁擦锣却穿万元西装）。 |
| 反转合理 | 2 | 情节转折是否由角色主动选择或职场逻辑驱动。9-10分：反转基于前期伏笔（如助听器、系统漏洞、旧情书）；5分以下：依赖巧合（如恰好路过救人）或降智对手（如相亲男当众扬言打人）。 |
| 情绪感染 | 2 | 能否让读者共情主角职场困境与情感挣扎。9-10分：通过内心独白或细节传递复杂情绪（如暗恋卑微、查父真相的执念）；5分以下：情绪扁平（只有愤怒或脸红），或靠旁白强行告知（如‘她很难过’）。 |
| 节奏控制 | 1 | 信息密度与情节推进是否匹配职场婚恋的慢热特性。9-10分：开篇快速建立冲突，但情感发展留有呼吸感（如多次错位相遇）；5分以下：前五章塞入过多事件（跟踪、搬家、初遇、认邻），导致情感失焦。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "女频/职场婚恋"
```

`--genre` 会把 `assets/prompts/女频/职场婚恋.txt` 追加到默认写作规范之后。（本题材的规则层目前只有套路和评分维度，没有迭代出的细则。）
