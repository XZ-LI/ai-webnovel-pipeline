# 女频衍生（女频）写作模版

英文名：Female Fan Fiction Derivative
成熟度：**B 级** — 有语料库反推的评分维度，写作规则未迭代

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 穿进熟知的 IP（剧、小说、游戏）
- 女主知道原作剧情并着手改写
- 救下注定要死的角色，或把悲剧改道
- 对虚构套路的自觉带来笑点
- 一边爱着原作一边改掉它，情绪由此产生

## 推荐开局钩子

女主认出自己进了哪个故事，并第一次脱离原本的剧本

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 钩子强度 | 3 | 开篇是否在300字内迅速建立核心悬念或情感冲击，引发读者继续阅读的强烈欲望。9-10分：以高情绪密度台词、命运反转或系统任务直接切入主线；5分以下：冗长背景铺垫、无冲突日常或模糊设定。 |
| 人设鲜活 | 3 | 角色是否通过细节、语言或心理展现独特性格与动机。9-10分：言行符合身份且有反差萌（如鬼魂起名‘池烟’）、内心矛盾真实；5分以下：标签化（纯善/纯恶）、无个性对话或行为逻辑断裂。 |
| 衍生融合 | 3 | 对原作世界观、人物关系与时代逻辑的尊重与创新平衡。9-10分：精准复刻原剧语境（如包衣佐领设定），并合理拓展新视角；5分以下：篡改核心人设（如年世兰变圣母）或无视历史框架导致OOC。 |
| 情感共鸣 | 3 | 能否引发读者对角色处境的共情或代入。9-10分：通过具体创伤（丧子、被打死）或亲情羁绊（姐弟相守）触发情绪共振；5分以下：空洞抒情或强行卖惨无细节支撑。 |
| 节奏把控 | 2 | 信息释放与情节推进的疏密是否匹配读者期待。9-10分：每章有明确进展（如穿成身份确认、任务启动），避免拖沓；5分以下：大段说明性文字、重复心理描写或无效对话堆砌。 |
| 系统设计 | 2 | 金手指/系统的规则是否清晰、有代价且推动剧情。9-10分：机制新颖（幸福值兑换心愿）、限制明确（5分崩塌）；5分以下：万能外挂无约束或规则模糊导致剧情失控。 |
| 对话自然 | 2 | 角色语言是否符合身份、时代与情境。9-10分：宫廷用语得体（‘福晋’‘爷’）、性格化（夏冬春咋呼vs安陵容谦卑）；5分以下：现代口语泛滥或全员同质化台词。 |
| 悬念铺设 | 2 | 章节结尾或关键节点是否埋设有效钩子。9-10分：用未解之谜（宜修重生疑云）、危机预告（去贾府风险）促读；5分以下：平铺直叙无留白或强行中断无实质内容。 |
| 成长伏笔 | 2 | 是否暗示主角能力/认知的演变可能。9-10分：通过初始困境（孤儿穿书）与资源限制（积分兑换）铺垫成长线；5分以下：开局无敌或被动接受命运无主动性。 |
| 画面营造 | 1 | 场景与动作描写是否具象可感。9-10分：细节精准（‘三百二十六块砖石’‘腐烂只剩几块烂肉的尸体’）；5分以下：抽象概括（‘她很悲伤’‘宫殿很大’）无视觉锚点。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "女频/女频衍生"
```

`--genre` 会把 `assets/prompts/女频/女频衍生.txt` 追加到默认写作规范之后。（本题材的规则层目前只有套路和评分维度，没有迭代出的细则。）
