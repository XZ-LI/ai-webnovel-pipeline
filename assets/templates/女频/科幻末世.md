# 科幻末世（女频）写作模版

英文名：Sci-Fi Apocalypse (Female)
成熟度：**B 级** — 有语料库反推的评分维度，写作规则未迭代

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 末世世界带异能（尸潮、外星、虚空生物）
- 女主觉醒稀有或被低估的能力
- 先活命再谈情——决策务实甚至狠辣
- 基地建设与资源调度和动作线并行
- 男主敬重她的强，不走“弱女待救”那套

## 推荐开局钩子

女主在生死一刻第一次动用觉醒的能力

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 末世钩子 | 3 | 开篇是否在300字内建立强烈的末世危机感或生存紧迫性。9-10分：直接呈现灾难爆发、倒计时、异常征兆等高张力情境；5分以下：用回忆、日常琐事或冗长设定铺垫，缺乏即时威胁。 |
| 金手指合理性 | 3 | 主角特殊能力（空间、重生、系统等）的引入是否符合末世逻辑且有代价/限制。9-10分：能力与世界观融合自然，伴随风险或资源消耗；5分以下：无解释突兀获得无敌外挂，无视社会规则或物理法则。 |
| 秩序崩塌感 | 3 | 是否有效呈现社会结构瓦解过程（政府失效、法律真空、资源争夺）。9-10分：通过细节展现权力真空下的混乱与人性博弈；5分以下：默认‘国家消失’却不描写过渡，或主角行为完全无视现存秩序。 |
| 生存细节 | 2 | 物资筹备、避险策略等求生行为是否专业可信。9-10分：包含具体品类、保质期、替代方案等硬核细节；5分以下：笼统写‘囤积物资’或依赖空间无限保鲜，缺乏实操逻辑。 |
| 角色动机 | 2 | 主角行动是否源于清晰的末世生存目标而非情绪化复仇。9-10分：目标与末世特性强相关（如建立基地、研发疫苗）；5分以下：沉迷打脸虐渣、情爱纠葛，忽视宏观危机。 |
| 异能逻辑 | 2 | 超自然能力是否遵循自洽规则（升级路径、能量消耗、弱点）。9-10分：能力有明确边界与进化条件；5分以下：随剧情需要随意增强，无代价无制约。 |
| 群像张力 | 2 | 配角是否构成有效冲突或协作网络。9-10分：配角有独立立场与利益诉求，推动剧情；5分以下：全员工具人，只为衬托主角。 |
| 灾难层次 | 2 | 末世威胁是否多维度展开（丧尸、天灾、资源枯竭等）。9-10分：复合型灾难叠加，形成生存压力链；5分以下：仅单一丧尸威胁，无环境恶化描写。 |
| 体制对抗 | 2 | 是否呈现个人与组织/国家机器的博弈。9-10分：主角需周旋于官方势力获取资源或规避监管；5分以下：完全无视体制存在，或体制沦为背景板。 |
| 反转密度 | 1 | 每千字是否包含至少1个颠覆预期的情节转折。9-10分：反转紧扣末世特性（如人类比丧尸更危险）；5分以下：线性推进无意外，或反转脱离世界观。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "女频/科幻末世"
```

`--genre` 会把 `assets/prompts/女频/科幻末世.txt` 追加到默认写作规范之后。（本题材的规则层目前只有套路和评分维度，没有迭代出的细则。）
