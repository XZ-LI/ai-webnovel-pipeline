# 星光璀璨（女频）写作模版

英文名：Entertainment Circle Romance
成熟度：**B 级** — 有语料库反推的评分维度，写作规则未迭代

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 女主进入娱乐圈（演戏、唱歌、综艺）
- 她藏着真才实学或一段让业内震动的旧身份
- 舆情处理、黑粉、圈内政治
- 男主是顶流，或是幕后掌权者
- 两人都有台前人格与台下人格的强烈反差

## 推荐开局钩子

女主第一次公开露面，以意料之外的方式爆火

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 钩子强度 | 3 | 开篇是否在300字内制造强烈情绪冲击或认知颠覆，引发读者‘必须看下去’的冲动。9-10分：首段即出现高能反转、极端行为或身份错位；5分以下：平铺直叙背景设定，无即时冲突。 |
| 人设反差 | 3 | 主角是否具备鲜明、反套路的性格标签，并通过言行快速立住形象。9-10分：角色言行高度统一且具记忆点（如‘讨死型人格’）；5分以下：性格模糊，行为逻辑随剧情需要随意切换。 |
| 节奏爆点 | 3 | 每千字是否包含至少1个情绪或情节爆点（打脸、发疯、反转等）。9-10分：密集安排高能场面，无冗余描写；5分以下：大段心理独白或环境描写稀释戏剧张力。 |
| 打脸爽感 | 3 | 主角反击是否兼具速度、创意与羞辱性，让读者获得即时情绪宣泄。9-10分：打脸手段出人意料且符合人设（如直播喊话捅人者）；5分以下：依赖他人解围或事后报复。 |
| 悬念钩链 | 3 | 章节结尾是否设置强悬念，迫使读者点击下一章。9-10分：用身份揭露、新危机或神反转收尾（如摘面具）；5分以下：自然停顿或总结式结尾。 |
| 玩梗密度 | 2 | 是否高频使用贴合人设的网络热梗、谐音梗或自创梗，形成语言风格标识。9-10分：每章有2个以上原创梗且自然融入剧情；5分以下：强行插入过时梗或无梗纯叙述。 |
| 世界观融合 | 2 | 娱乐圈/豪门等设定是否通过细节自然呈现，而非生硬说明。9-10分：用热搜词条、综艺规则、资本操作等真实行业元素推动剧情；5分以下：仅用‘顶流’‘财阀’等标签堆砌。 |
| 对话锋芒 | 2 | 角色对话是否简短有力、充满攻击性或幽默感，推动冲突升级。9-10分：每句台词兼具信息量与情绪杀伤力（如‘你活爹来了’）；5分以下：大量解释性对白或礼貌寒暄。 |
| 情绪浓度 | 2 | 文字是否持续输出高强度情绪（癫狂、愤怒、嘲讽等），避免平淡过渡。9-10分：通篇保持情绪峰值，无冷静期；5分以下：频繁切换情绪状态或大段中性叙述。 |
| 品类创新 | 1 | 是否在‘发疯文学+娱乐圈’框架下加入新元素（如修仙、身体互换）。9-10分：核心设定有独特变体（如渡劫失败穿书）；5分以下：完全复刻‘假千金被退婚’模板。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "女频/星光璀璨"
```

`--genre` 会把 `assets/prompts/女频/星光璀璨.txt` 追加到默认写作规范之后。（本题材的规则层目前只有套路和评分维度，没有迭代出的细则。）
