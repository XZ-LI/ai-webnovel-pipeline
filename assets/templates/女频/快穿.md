# 快穿（女频）写作模版

英文名：Quick Transmigration
成熟度：**B 级** — 有语料库反推的评分维度，写作规则未迭代

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 女主穿越多个世界完成系统任务
- 每个世界换一个题材（古代、现代、奇幻、末世）
- 跨世界保持同一内核人格，方法随场景变
- 男主魂魄跟着她穿，每世都能认出她
- 每个世界都有一段对白莲花或反派的打脸线

## 推荐开局钩子

女主落进新世界，迅速把处境判断清楚

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 钩子强度 | 3 | 开篇是否在300字内建立强烈悬念或冲突，引发读者继续阅读的欲望。9-10分：首段即呈现身份错位、生死危机或情感张力；5分以下：平铺直叙日常场景无冲突，或系统说明冗长拖沓。 |
| 人设反差 | 3 | 主角穿越前后或表里人格是否形成鲜明对比，制造戏剧张力。9-10分：表面行为与内心算计/真实身份形成强烈反差；5分以下：角色扁平，言行一致无层次，或反差生硬不合逻辑。 |
| 节奏密度 | 3 | 单位篇幅内信息量与情节推进效率。9-10分：每章包含至少一个剧情转折+任务进展+人物互动；5分以下：大段心理独白、重复日常或无效对话拖慢节奏。 |
| 反派塑造 | 3 | 任务对象（反派/男主）是否具备复杂动机与压迫感。9-10分：反派行为有合理创伤根源，气场强大且与女主产生化学反应；5分以下：反派仅标签化‘冷血’‘偏执’，无具体行为支撑。 |
| 任务张力 | 3 | 主线任务是否制造紧迫感与道德困境。9-10分：任务失败代价明确（如死亡/黑化值飙升），且与角色情感产生冲突；5分以下：任务目标模糊，或完成方式过于简单无风险。 |
| 系统融合 | 2 | 系统功能是否自然嵌入剧情，而非机械报幕。9-10分：系统交互推动决策或制造笑点/危机；5分以下：系统仅用于解释设定，对话僵硬如说明书。 |
| 世界贴合 | 2 | 小世界设定是否细节扎实，符合类型逻辑。9-10分：现代校园有阶层差异、古代乱世显官场腐败，细节服务核心矛盾；5分以下：背景空洞，仅套用标签（如‘豪门’‘末世’）无具体规则。 |
| 对话锋芒 | 2 | 对话是否体现角色立场交锋或隐藏信息。9-10分：台词暗含试探、威胁或双关，推动关系变化；5分以下：对话仅用于交代信息，无潜台词或情绪对抗。 |
| 反转设计 | 2 | 情节是否在预期中制造合理意外。9-10分：利用读者对原剧情认知设局，主角破局方式出人意料但逻辑自洽；5分以下：反转依赖巧合或强行降智。 |
| 情感锚点 | 2 | 是否建立读者共情支点（如主角软肋/信念）。9-10分：主角有明确守护对象（如家人/自我尊严）或价值观，驱动行为；5分以下：主角仅机械完成任务，无情感内核。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "女频/快穿"
```

`--genre` 会把 `assets/prompts/女频/快穿.txt` 追加到默认写作规范之后。（本题材的规则层目前只有套路和评分维度，没有迭代出的细则。）
