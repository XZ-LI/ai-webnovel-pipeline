# 历史古代（男频）写作模版

英文名：Historical / Ancient China
成熟度：**A 级** — 已迭代 10 轮，采用第 5 轮（评审分 7.5）

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 朝堂权斗、宦官当道、后宫博弈
- 军事谋略与大规模战役
- 科举与文官体系的升迁逻辑
- 在森严等级里靠才干或心术逆袭
- 考据扎实的风俗、饮食、服制与建筑

## 推荐开局钩子

主角初入朝堂，或在一次刺杀中侥幸活命

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 史感 | 3 | 9-10分：细节符合时代制度、地理与官职考据；用语、器物、礼制自然融入剧情而非硬塞。5分以下：现代口吻、科技或官职强行植入，缺乏年代辨识度。 |
| 节奏 | 3 | 9-10分：动静结合，危机—缓冲—升级层层递进；场景转换自然，读者始终在剧情驱动中前进。5分以下：长篇回忆或说明中断情节，打斗与闲聊脱节。 |
| 人物 | 3 | 9-10分：出场即显性格与立场，多角色对戏能形成鲜明对比；言行自洽可成长。5分以下：脸谱化、功能化，换名不影响剧情。 |
| 矛盾 | 3 | 9-10分：主线矛盾早露头且具时代厚度，如门阀争权、藩王夺嫡；冲突双方势力与利益清晰。5分以下：主角一直顺风顺水或矛盾模糊。 |
| 钩子 | 2 | 9-10分：开篇一句或一幕就抛出危局、异象或重大信息，引发读者即时提问；2-3段内完成时空、主角处境与风险的展示。5分以下：开场日常流水、无紧迫感，读者三页内仍不知道主角要面对什么。 |
| 对话 | 2 | 9-10分：符合身份阶层与时代措辞，信息量与情绪并进，有听感。5分以下：对白成资讯堆砌或现代网络语频出。 |
| 画面 | 2 | 9-10分：景象具层次、动静兼备，可触及五感；历史元素（服饰、兵器、建筑）与气氛相辅。5分以下：场景白描或堆词无重点。 |
| 悬念 | 2 | 9-10分：不断抛出身份、时代、阴谋等未知点，并留信息缺口促读者猜测。5分以下：情节线性无疑问或过早解答。 |
| 反转 | 1 | 9-10分：关键节点给出逻辑自洽且出其不意的情节跌宕，改变人物命运或局势。5分以下：铺垫不足的生硬转折或全无变化。 |
| 情感 | 1 | 9-10分：人物情绪真实递进，引发时代共情（家国、亲情、忠义）。5分以下：生硬说教或情绪缺位。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "历史古代"
```

`--genre` 会把 `assets/prompts/男频/历史古代.txt` 追加到默认写作规范之后。
