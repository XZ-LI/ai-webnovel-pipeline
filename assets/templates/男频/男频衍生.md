# 男频衍生（男频）写作模版

英文名：Male-Oriented Fan Fiction
成熟度：**B 级** — 有语料库反推的评分维度，写作规则未迭代

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 穿书、穿游戏或穿影视世界
- 主角靠对剧情的自觉避开原作死线
- 凭先知提前招揽原作角色
- 改写反派命运，或站到“注定输”的那一方
- 带后宫或兄弟情元素的爽文结构

## 推荐开局钩子

主角认出自己穿进了哪个世界

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 钩子强度 | 3 | 开篇是否在300字内建立强烈悬念或情绪冲击。9-10分：首段即引爆核心冲突（如死亡重生、系统绑定、命格觉醒），语言极具张力；5分以下：平铺直叙背景设定，无即时危机或反转。 |
| 人设锐度 | 3 | 主角是否具备鲜明、反套路的男频特质（如狠戾、清醒、利己）。9-10分：角色动机清晰且具攻击性（如‘权力守护财富’‘截胡不缺德’），言行体现阶层认知；5分以下：圣母心泛滥或被动接受命运，缺乏主动破局意识。 |
| 权谋密度 | 3 | 政治/势力博弈是否具象化为可操作的策略。9-10分：展现具体派系计算（如‘梁家非整体’‘赵立春败则全局崩’），决策有现实官场逻辑支撑；5分以下：仅喊口号‘我要上位’，无路径拆解或对手分析。 |
| 衍生贴合 | 3 | 对原作人物/事件的重构是否符合原著逻辑并深化矛盾。9-10分：利用原作留白进行合理推演（如祁同伟‘惊天一跪’的前因后果）；5分以下：扭曲角色本质（如沙瑞金变脸谱反派）或无视原作时间线。 |
| 情绪锚点 | 3 | 是否植入引发男频共鸣的核心情绪（如屈辱、不甘、掌控欲）。9-10分：精准戳中‘寒门难跃阶’‘英雄被工具化’等痛点；5分以下：情绪悬浮，依赖外部刺激而非内在驱动。 |
| 机缘代价 | 2 | 金手指或重生优势是否伴随明确风险与限制。9-10分：系统/先知能力需付出道德或物理代价（如‘截胡需激活’‘噬运杀人夺寿’）；5分以下：无条件开挂，能力获取零成本零后果。 |
| 节奏压强 | 2 | 章节内是否高频推进关键事件。9-10分：每千字至少一个决策点或转折（如退股、清关系户、赴港夺照）；5分以下：大段回忆、环境描写或无效对话稀释主线。 |
| 台词锋芒 | 2 | 对话是否承载立场交锋与信息密度。9-10分：每句台词暗含权力试探或身份揭示（如‘请医生’vs‘叫医生’）；5分以下：日常寒暄堆砌，无潜台词或冲突。 |
| 升级可视 | 2 | 力量/地位提升是否有具象化里程碑。9-10分：明确标出阶段目标（如‘进部’‘副省部级’‘寿增一月’）；5分以下：模糊表述‘变强了’‘混得不错’，无量化参照。 |
| 反派压迫 | 2 | 对立势力是否构成真实威胁。9-10分：敌人具备资源、智商或制度性优势（如梁群峰‘不经意倾向即可致人寸步难行’）；5分以下：反派降智送经验，无实质阻碍。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "男频衍生"
```

`--genre` 会把 `assets/prompts/男频/男频衍生.txt` 追加到默认写作规范之后。（本题材的规则层目前只有套路和评分维度，没有迭代出的细则。）
