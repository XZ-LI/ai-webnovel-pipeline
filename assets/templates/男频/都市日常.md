# 都市日常（男频）写作模版

英文名：Urban Slice of Life
成熟度：**B 级** — 有语料库反推的评分维度，写作规则未迭代

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 低冲突的主角，身上有一门独到手艺（厨艺、医术等）
- 与邻居、同事、陌生人之间的暖心互动
- 治愈叙事：在帮别人的过程中治好自己
- 口碑慢慢攒起来，不走强爽路线
- 对食物、市井、四季的感官描写丰沛

## 推荐开局钩子

主角到新城市/新工作的第一天，意外帮了某个人

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 钩子强度 | 3 | 开篇是否在300字内制造强烈悬念或反常情境，引发读者继续阅读的冲动。9-10分：以非常规事件（如被抓进派出所、神秘预言）切入，打破日常预期；5分以下：平铺直叙入学、搬家等常规流程，无情绪张力。 |
| 人设鲜活 | 3 | 角色是否通过细节动作、语言或心理展现独特性格与成长潜质。9-10分：人物有辨识度（如高冷学姐冒雨前行、继姐捏后颈威胁），行为符合逻辑且带反差；5分以下：角色标签化（如‘温柔学姐’‘霸道总裁’）无具体行为支撑。 |
| 日常戏剧 | 3 | 能否将平凡校园/生活场景转化为有张力的小型戏剧事件。9-10分：普通事件（如军训、图书馆避雨）嵌入巧合、误会或情感暗流；5分以下：流水账式记录吃饭、上课，无情节推进或情绪波动。 |
| 情感真实 | 2 | 主角内心活动是否细腻可信，避免强行煽情或机械降神。9-10分：情绪转变有铺垫（如暗恋破灭后的自我和解），心理描写贴合年龄与处境；5分以下：突兀告白、秒变深情，或情绪全靠旁白说明。 |
| 节奏把控 | 2 | 章节内信息密度与停顿是否平衡，避免拖沓或仓促。9-10分：关键情节（如派出所误会）快速推进，穿插环境/心理留白（如雨夜网咖）调节呼吸感；5分以下：大段背景解说打断叙事，或连续事件无缓冲导致疲劳。 |
| 对话自然 | 2 | 角色对话是否符合身份、年龄及关系亲疏，避免说教或工具化。9-10分：口语化且带个性（如王大锤‘我滴天’、林伊‘美得你’），推动剧情或揭示关系；5分以下：对话仅为交代设定，或学生说话像教授。 |
| 悬念设计 | 2 | 章节结尾或关键节点是否埋设可延展的疑问。9-10分：悬念与主线强相关（如佛像长成、老道再现），引发对后续发展的合理推测；5分以下：强行断章（如‘突然，门开了！’）却无实质信息增量。 |
| 反差营造 | 2 | 是否利用身份、认知或情境反差制造趣味或张力。9-10分：反差推动剧情（如校花有男友传闻 vs 实则单身、炒粉工成策划师）；5分以下：反差仅为噱头（如‘首富装穷’）无后续展开。 |
| 世界观融 | 1 | 特殊设定（如风水、写作天赋）是否自然嵌入日常生活逻辑。9-10分：超常元素有现实锚点（如测字术结合经营策略、小说爆火源于真实情感）；5分以下：突兀插入金手指或规则，破坏都市真实感。 |
| 细节质感 | 1 | 环境、动作或物品描写是否具象且服务氛围。9-10分：细节精准唤起感官体验（如炒粉‘飞花点翠地舀盐’、雨夜‘毛毛细雨落在头上’）；5分以下：笼统形容词堆砌（如‘美丽的校园’‘精致的公寓’）。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "都市日常"
```

`--genre` 会把 `assets/prompts/男频/都市日常.txt` 追加到默认写作规范之后。（本题材的规则层目前只有套路和评分维度，没有迭代出的细则。）
