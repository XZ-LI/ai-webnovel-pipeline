# 动漫衍生（男频）写作模版

英文名：Anime-Derived Fan Fiction
成熟度：**A 级** — 已迭代 10 轮，采用第 5 轮（评审分 7.2）

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 穿进熟知的动漫或漫画世界
- 主角保有对原作剧情的先知视角
- 蝴蝶效应：原作主线被一点点改写
- 战力体系相对原作做了适配或增强
- 打破“反派必死”的定式——拉拢、感化甚至救下反派

## 推荐开局钩子

主角意识到自己落进了哪部作品的那一刻

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 钩子 | 3 | 指章节开头 200 字内抛出的戏剧张力与信息密度。9-10 分：一句话立即制造冲突或好奇点，并与读者熟悉的番剧设定挂钩；5 分以下：平铺日常、世界说明过长，读者无法在 30 秒内感知看点。 |
| 融设 | 3 | 原创设定与原作 IP（番剧/游戏）的无缝融合度。9-10 分：外挂、体系既补全原设空白又不违和；5 分以下：生硬贴皮，金手指与原 IP 逻辑冲突。 |
| 角塑 | 3 | 主要角色的个性立体度与二次元标签新鲜度。9-10 分：三句对话即可分辨性格且带“二设”彩蛋；5 分以下：脸谱化如‘腹黑学姐’、‘路人重生男’无差别。 |
| 对话 | 2 | 对白是否口吻贴合番剧语感并推动剧情。9-10 分：含弹幕梗、ACG黑话又不失信息量；5 分以下：对话冗长、口水化、角色自说自话。 |
| 节奏 | 2 | 升级、危机、日常三类段落的切换张弛。9-10 分：每 800～1200 字出现一次转折或信息坎；5 分以下：长篇内心独白或说明导致读者跳读。 |
| 悬链 | 2 | 连续悬念链的设计，即章节结尾留下的追读钩。9-10 分：结尾给出明确未知（身份暴露、任务时限）；5 分以下：自然结束或过度注水，读者无需点下一章。 |
| 情感 | 2 | 能否让读者共振或产生成分向的‘刀’与‘糖’。9-10 分：场景情绪有递进，兼顾二游玩家的意难平；5 分以下：喊口号、直白煽情，缺少细节。 |
| 画面 | 1 | 场景调度与镜头语言的动漫感。9-10 分：读者脑中能出分镜、色调；5 分以下：方位不清、动作描写流水账。 |
| 反哏 | 1 | 对经典套路的自嘲或反转力度。9-10 分：在系统文、败犬修罗场等常见桥段里制造预期落差；5 分以下：直线爽点，无意外。 |
| 代价 | 1 | 力量成长是否配套清晰代价或规则，契合番剧‘机缘/Flag’逻辑。9-10 分：外挂限制、阵营窥伺写得清楚；5 分以下：无限外挂不付成本，削弱紧张感。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "动漫衍生"
```

`--genre` 会把 `assets/prompts/男频/动漫衍生.txt` 追加到默认写作规范之后。
