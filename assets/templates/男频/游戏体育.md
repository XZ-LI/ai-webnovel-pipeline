# 游戏体育（男频）写作模版

英文名：Gaming / Sports
成熟度：**B 级** — 有语料库反推的评分维度，写作规则未迭代

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 主角成为电竞或传统体育项目的传奇选手
- 队内关系、宿敌、赛事线
- 对局内外关键决策的战术拆解
- 弱旅靠训练与关键比赛一路翻盘
- 部分子类型带系统或外挂式辅助

## 推荐开局钩子

一次关键球/关键局，彻底改变别人对主角的看法

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 钩子强度 | 3 | 开篇是否在300字内建立强烈悬念或反差，引发读者继续阅读的冲动。9-10分：首段即抛出颠覆性设定、生死危机或身份反转；5分以下：平铺直叙背景介绍，无即时冲突或情绪张力。 |
| 系统融合 | 3 | 游戏/体育规则、数值体系是否自然嵌入叙事，而非生硬罗列。9-10分：系统信息通过角色行动、环境互动或危机应对展现，数据服务于剧情；5分以下：大段静态面板复制粘贴，打断节奏且无情节关联。 |
| 危机节奏 | 3 | 章节内是否维持‘压力-应对-新危机’的紧凑循环。9-10分：每千字至少一次小危机（资源短缺、怪物袭击、属性惩罚），且解决过程体现角色成长；5分以下：长时间无冲突，或危机解决依赖机械降神。 |
| 天赋代价 | 2 | 超凡能力是否伴随明确限制或负面效果。9-10分：SSS级天赋/金手指有克苏鲁式精神污染、道德困境或资源消耗等代价；5分以下：能力无短板，纯爽文式碾压。 |
| 品类沉浸 | 2 | 是否精准还原游戏/体育专业细节。9-10分：操作术语（如足球绕杆计数、网游仇恨机制）、装备参数（耐久/航速）符合品类真实逻辑；5分以下：用模糊词汇替代专业表述（如‘超强技能’‘厉害装备’）。 |
| 角色弧光 | 2 | 主角是否通过章节事件展现性格特质或转变。9-10分：用具体行动（如自制毒矛、拒绝镀金球衣）替代内心独白证明人设；5分以下：标签化宣言（‘我要变强！’）无行为佐证。 |
| 悬念设计 | 2 | 章节结尾是否埋设可延展的未知要素。9-10分：用物品（漂流宝箱）、状态异常（存活概率98.56%）或NPC异动（邪神乌鸦）制造下一章必读理由；5分以下：章节结束于日常休息或无后续的动作。 |
| 反差张力 | 2 | 是否制造身份/能力预期与现实的戏剧冲突。9-10分：SSS天赋配C级表象（叶白）、邪神走狗vs公爵千金（维克托）等错位引发连锁反应；5分以下：主角能力与处境完全匹配，无认知颠覆。 |
| 资源焦虑 | 2 | 是否营造稀缺资源下的决策压力。9-10分：食物/理智/时间等关键资源精确量化（如理智100/100），消耗直接影响生存；5分以下：资源无限或获取无代价。 |
| 世界观渗透 | 1 | 设定信息是否通过环境、道具或对话自然流露。9-10分：用骸骨燧发枪暗示前文明崩溃，聊天频道反映社会结构；5分以下：大段背景说明打断叙事（如工作人员念稿式历史课）。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "游戏体育"
```

`--genre` 会把 `assets/prompts/男频/游戏体育.txt` 追加到默认写作规范之后。（本题材的规则层目前只有套路和评分维度，没有迭代出的细则。）
