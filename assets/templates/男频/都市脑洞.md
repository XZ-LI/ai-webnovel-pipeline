# 都市脑洞（男频）写作模版

英文名：Urban Brain Holes
成熟度：**B 级** — 有语料库反推的评分维度，写作规则未迭代

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 现代都市背景 + 一个极度反常的设定
- 主角靠横向思维或荒诞能力解决问题
- 对职场文化、互联网风气、消费社会的讽刺
- 把日常情境推到极端而生出的喜剧
- 带元叙事意味、贴着第四面墙的幽默

## 推荐开局钩子

开场第一个场景就把荒诞设定摆出来

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 钩子强度 | 3 | 开篇是否在300字内抛出强烈冲突、反常设定或命运转折，让读者产生‘必须看下去’的冲动。9-10分：开篇即高能，用极端情境+身份反差+系统/金手指亮相制造张力；5分以下：平铺直叙日常，无悬念无冲突，靠大段背景介绍拖节奏。 |
| 脑洞新颖 | 3 | 核心设定是否突破套路，在都市背景下融合超现实元素形成独特爽感逻辑。9-10分：金手指机制与世界观深度咬合（如运气值兑换赶海工具、直播圈钱触发随机奖励）；5分以下：直接套用‘签到系统’‘神豪卡’等泛滥模板，无差异化设计。 |
| 爽感逻辑 | 3 | 金手指收益是否遵循‘努力-回报’或‘代价-补偿’原则，避免无脑开挂。9-10分：系统奖励需付出合理行动（如赶海挖货换功勋值），且存在明确限制（如适时幸运值耗尽）；5分以下：开局天降万亿资产，无风险无挑战。 |
| 品类自觉 | 3 | 是否精准调用都市脑洞文的核心爽点模块（如系统任务、直播互动、读档轮回）。9-10分：熟练组合品类元素形成独特配方（如病娇AI+读档机制+真结局通关条件）；5分以下：混杂玄幻修仙等非都市元素，或忽略系统文基本规则。 |
| 节奏密度 | 2 | 单位篇幅内是否高频推进剧情、解锁新功能或制造小高潮。9-10分：每千字至少完成一次‘目标-行动-反馈’闭环（如挖蛏子→涨幸运值→换工具）；5分以下：大段静态描写、无效对话或重复行为无进展。 |
| 人设反差 | 2 | 主角是否具备内外矛盾特质（如怂包身体+钓鱼佬灵魂），配角是否有记忆点。9-10分：主角行为与身份形成戏剧张力（如圈钱主播自嘲‘面子都是大哥给的’），配角一句台词立住形象（如阿和说‘爷们吃他家的是给面子’）；5分以下：主角纯龙傲天无弱点，配角工具人化。 |
| 悬念嵌套 | 2 | 是否在解决小问题时埋下更大谜团，形成多层追问链。9-10分：当前目标达成同时引出新危机（如卖货赚钱后暗示‘顾三家养羊’为后续冲突伏笔）；5分以下：问题孤立解决，无后续牵引。 |
| 对话锋芒 | 2 | 人物语言是否符合身份且自带冲突性或幽默感。9-10分：台词推动剧情或暴露性格（如狂哥直播喷‘设计师退网’反被冻哭）；5分以下：对话冗长无信息量，如‘你好吗’‘我很好’式寒暄。 |
| 代价显性 | 2 | 金手指或机遇是否伴随明确风险或道德困境。9-10分：能力使用有可见成本（如直播圈钱透支健康值↓），或引发伦理挣扎（如长征副本中NPC牺牲）；5分以下：主角获益毫无代价，世界为其服务。 |
| 感官沉浸 | 1 | 是否通过细节描写激活读者五感，强化场景真实感。9-10分：用具体物象构建环境（如‘发黄劳动手套’‘黑馒头冷硬感’）；5分以下：仅用‘很美’‘很冷’等抽象形容词。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "都市脑洞"
```

`--genre` 会把 `assets/prompts/男频/都市脑洞.txt` 追加到默认写作规范之后。（本题材的规则层目前只有套路和评分维度，没有迭代出的细则。）
