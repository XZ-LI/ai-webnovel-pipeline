# 东方仙侠（男频）写作模版

英文名：Eastern Cultivation (Xianxia)
成熟度：**A 级** — 已迭代 10 轮，采用第 7 轮（评审分 7.6）

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 主角起点低，后被发现身负隐藏天赋或稀有体质
- 境界体系明确：炼气 → 筑基 → 金丹 → 元婴 → 更高
- 宗门、寻宝、灵石、丹药构成资源体系
- 同辈竞争、背叛、复仇驱动成长
- 上古遗迹、传承机缘、神兵利器

## 推荐开局钩子

主角第一次突破境界，或一场宗门试炼出了意外

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 钩子 | 3 | 0-4分：平铺直叙或先堆砌背景，首屏无冲突、无异象，读者三秒难以入戏；9-10分：首段即给出强冲击场面、超纲设定或生死/权力对峙，并嵌入品类元素（修为威压、仙器、宗门规矩）。 |
| 世界 | 3 | 衡量设定厚度与融入度。0-4分：只有模糊‘修仙界’、‘某朝’等标签，无具体地名、宗门制度；9-10分：空间层级、宗族/朝廷/宗门权力链清晰，修炼资源、仪式、禁忌与剧情动作天然结合，无生硬说明。 |
| 升级 | 3 | 东方仙侠核心爽点：境界、机缘与代价。0-4分：修炼体系模糊、主角实力变化靠‘突觉厉害’；9-10分：境阶命名+资源消耗+风险回报一体，机缘有门槛有成本。 |
| 角色 | 3 | 看人物是否立体并推动情节。0-4分：脸谱化‘天才’‘纨绔’，无特征行为; 9-10分：人设有多重欲望与矛盾，言行自洽，配角亦能留痕。 |
| 节奏 | 2 | 关注冲突/信息/缓冲的节拍。0-4分：长篇自述或连续战斗，缺少转折; 9-10分：3-5千字内完成‘铺-压-解/悬’循环，张弛有度并服务升级主线。 |
| 对话 | 2 | 衡量台词是否符合身份、时代与修真语感。0-4分：现代网络语滥用或信息冗余；9-10分：既保留古意又简练有力，可显修真哲理或权谋锋芒。 |
| 悬念 | 2 | 冲突未解+信息留白的张力。0-4分：主问题一揭即解或无后续隐患；9-10分：埋下身份、阴谋、因果线，多层未知驱动读者翻页。 |
| 情感 | 2 | 是否能激发同理心或热血。0-4分：打打杀杀无情绪波折；9-10分：悲悯、亲情、师徒等情感与修真环境自然交织。 |
| 仙味 | 1 | 宏大、神秘、出尘的东方想象力。0-4分：场面用现代俗语调侃，缺少道韵；9-10分：招式、器物、天地异象具诗意，阅读时有“拔俗”体验。 |
| 反转 | 1 | 戏剧性扭转与出其不意。0-4分：冲突线直来直去; 9-10分：关键节点出乎意料又合逻辑，常见于赐婚、宗门排名、身世揭晓等。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "东方仙侠"
```

`--genre` 会把 `assets/prompts/男频/东方仙侠.txt` 追加到默认写作规范之后。
