# 都市种田（男频）写作模版

英文名：Urban Farming / Building
成熟度：**B 级** — 有语料库反推的评分维度，写作规则未迭代

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 主角从零做起一片空间、一座农场或一门生意
- 带点玄学的生产体系：灵土、异种作物、随身空间
- 财富慢慢累积，顺带把一方社区带起来
- 返乡叙事与亲缘关系的修补
- 乡土朴素价值观与城市权钱阶层的对照

## 推荐开局钩子

主角发现灵田，或拿到种田系统

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 开篇钩子 | 3 | 衡量第一章前300字是否能迅速抓住读者注意力。9-10分：在3句话内建立强烈好奇、反差或危机感，如主角遭遇超常事件或做出反常规决定；5分以下：平铺直叙日常起居、冗长背景介绍或无冲突的内心独白。 |
| 人设鲜活 | 3 | 主角是否通过具体行为、语言或细节展现独特性格。9-10分：主角有辨识度高的习惯、价值观或矛盾特质（如教授身份却甘守荒山）；5分以下：主角言行模板化（如重生后只会哭喊‘我错了’），缺乏个性细节支撑。 |
| 种田实感 | 3 | 对‘种田’元素（采集、养殖、经营、年代生活等）的描写是否真实可信且具专业细节。9-10分：包含可验证的动植物知识、生产流程或时代生活细节（如昆仑山雪季厚度、1979年四合院结构）；5分以下：泛泛而谈‘搞点山货’‘发家致富’，无具体操作或时代特征。 |
| 情感锚点 | 3 | 是否建立能引发共情的核心关系或责任（如亲子、守护、赎罪）。9-10分：主角与他人/动物形成明确情感纽带（如被迫养雪豹幼崽），动机清晰；5分以下：情感空洞（如‘我要改变命运’无具体对象）或强行煽情。 |
| 品类调性 | 3 | 是否契合都市种田‘治愈/慢节奏/生活流’核心体验。9-10分：文字传递宁静感或微小确幸（如层林尽染的山景、直播互动温情）；5分以下：充斥打斗、阴谋等非种田元素，节奏急促压抑。 |
| 节奏张弛 | 2 | 章节内信息密度与情绪起伏是否合理。9-10分：日常采集/生活描写（松）与突发事件（紧）交替出现（如捡松鼠→被砸榛子→遇雪豹），每千字至少一次小转折；5分以下：长时间单一线性叙事（如纯回忆或纯对话）无推进。 |
| 世界融合 | 2 | 超现实元素（系统、重生、动物通灵等）是否自然融入都市背景。9-10分：奇幻设定有合理限制或解释（如平行世界提示+动植物考据）；5分以下：金手指突兀出现无铺垫（如突然获得能力却不交代来源）。 |
| 对话功能 | 2 | 对话是否推动剧情、揭示性格或传递关键信息。9-10分：每段对话有明确目的（如直播弹幕交代背景、雪豹台词推进收养线）；5分以下：对话仅为填充字数（如反复确认‘你没事吧？’‘我没事’）。 |
| 悬念设计 | 2 | 章节结尾是否埋设待解问题或期待点。9-10分：结尾留有具体疑问（如‘怀得有点多了，生不下’暗示后续接生危机）；5分以下：章节结束于平淡动作（如‘他沉沉睡去’）无后续牵引。 |
| 逻辑自洽 | 2 | 情节发展是否符合基本因果与角色能力边界。9-10分：事件有合理前因（如狗叼雪豹因主角提过养猫），主角行动受限于现实条件；5分以下：机械降神（如突然获赠巨款）或无视常识（如深山随意直播无信号问题）。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "都市种田"
```

`--genre` 会把 `assets/prompts/男频/都市种田.txt` 追加到默认写作规范之后。（本题材的规则层目前只有套路和评分维度，没有迭代出的细则。）
