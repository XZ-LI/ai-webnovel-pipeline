# 传统玄幻（男频）写作模版

英文名：Traditional Xuanhuan / High Fantasy
成熟度：**A 级** — 已迭代 10 轮，采用第 6 轮（评审分 7.8）

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 辽阔大陆：王国、帝国、妖兽领地并存
- 独创的力量体系（元素、血脉、阵法）
- 主角从籍籍无名走到搅动天下格局
- 世家与皇族之间的权谋倾轧
- 远古神魔与历史级灾变留下的余波

## 推荐开局钩子

主角得到一份强大传承，或眼睁睁看着它被夺走

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 开篇钩 | 3 | 评估章节开头5-8行能否迅速抛出事件、人物或利益冲突；9-10分＝一句话即可引爆读者情绪并自然导出世界观；5分以下＝平铺直叙、信息真空，读者无继续阅读冲动。 |
| 节奏感 | 3 | 看推进速度与张弛：高潮—过渡—信息——反转衔接紧凑且逻辑清晰计9-10分；情节拖沓或跳跃混乱则≤5分。 |
| 人设度 | 3 | 人物是否立体、动机鲜明且能在首次出场就留下记忆点；9-10分＝言行与身份高度贴合并具反差；≤5分＝模板式“天才/废柴”无独特痕迹。 |
| 画面感 | 2 | 场景描绘是否调动视觉与动态，辅以听觉/气味等多感官；9-10分＝读者能在脑海“看到电影”；≤5分＝纯告知式说明。 |
| 对话味 | 2 | 对白是否符合身份、地域与年代口吻，并承担推动、揭示、冲突功能；9-10分＝信息量＋性格双重服务；≤5分＝口语单调或尬文言。 |
| 悬念度 | 2 | 看是否持续抛出未解之问（身份、目标、阴谋）并递进；9-10分＝章节末仍留下关键未知，读者必须点下一章；≤5分＝谜底当场揭光或无悬念。 |
| 升级线 | 2 | 修炼/权力阶梯是否清晰且与剧情同步推进；9-10分＝境界体系可量化、目标明确且每步伴随成本或剧情节点；≤5分＝境界名堆砌、实力变化随意。 |
| 机缘价 | 2 | 奇遇是否伴随相应代价/风险，避免白给；9-10分＝机会与牺牲成正比，增强可信度；≤5分＝送功法送宝物“无代价”。 |
| 宗政戏 | 1 | 宗门/皇朝/家族权谋描写是否合理驱动冲突；9-10分＝势力利益链清晰、对话暗藏博弈；≤5分＝势力仅作背景板。 |
| 章异度 | 1 | 同一作品连续章节是否提供不同场景/情绪/信息，避免机械重复；9-10分＝一章一亮点，且风格互补；≤5分＝打怪或自白循环。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "传统玄幻"
```

`--genre` 会把 `assets/prompts/男频/传统玄幻.txt` 追加到默认写作规范之后。
