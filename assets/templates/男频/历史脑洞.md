# 历史脑洞（男频）写作模版

英文名：Historical 'What If' / Brain Holes
成熟度：**B 级** — 有语料库反推的评分维度，写作规则未迭代

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 现代知识被移植进古代场景
- 主角抛出超越时代的发明或策略
- 改写著名战役或历史事件的结局
- 现代思维撞上古代规矩，产生笑料与反讽
- 靠先知快速攫取经济或军事优势

## 推荐开局钩子

主角第一次用现代知识在古代办成一件事

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 钩子强度 | 3 | 开篇是否在300字内建立强烈阅读驱动力。9-10分：用冲突、反常或悬念瞬间抓住读者，如主角身份与行为剧烈反差；5分以下：平铺直叙背景设定或冗长心理描写，无即时张力。 |
| 人设反差 | 3 | 主角是否具备鲜明且符合逻辑的性格/身份反差。9-10分：反差贯穿言行细节并推动剧情（如文官有神力、皇帝求速死）；5分以下：标签化设定（如‘冷酷杀手’‘腹黑王爷’）无具体行为支撑。 |
| 历史融合 | 3 | 脑洞设定与历史语境的有机咬合度。9-10分：金手指/行为逻辑符合时代限制（如利用贞观年间世家矛盾），改造历史有合理支点；5分以下：现代思维粗暴套用（如直接办报纸无视信息传播条件）。 |
| 脑洞锐度 | 3 | 核心创意的新颖性与执行精度。9-10分：设定有颠覆性且贯穿细节（如'功德圆满系统'绑定退位目标）；5分以下：缝合常见元素（重生+系统+争霸）无独特视角。 |
| 节奏密度 | 2 | 单位篇幅内有效信息量（冲突/转折/揭示）。9-10分：每300字至少一个情节推进点（如新冲突、金手指激活、关系反转）；5分以下：大段静态描写或重复情绪渲染无实质进展。 |
| 对话张力 | 2 | 对话是否承载冲突、揭示性格或推进剧情。9-10分：每句对话都有潜台词或功能（如李世民父子互怼暗藏继承危机）；5分以下：纯信息交代（'陛下，十八路诸侯来了'）或水词堆砌。 |
| 金手指代价 | 2 | 超常能力是否伴随合理制约或风险。9-10分：能力使用有明确代价（如李恪暴露仓库可能招致皇权猜忌）；5分以下：无敌流无短板（如万斤神力无体力消耗设定）导致戏剧性崩坏。 |
| 悬念闭环 | 2 | 章节结尾是否形成有效钩子。9-10分：用新危机/反转/抉择收尾（如赢毅骂太后后朝臣震动）；5分以下：自然停顿（如'他吃完了面饼'）或强行中断无实质悬念。 |
| 群像鲜活 | 1 | 配角是否具备独立动机与记忆点。9-10分：配角行为逻辑自洽且影响主线（如贾诩赌约展现老谋深算）；5分以下：工具人属性（如狱卒只会喊'开饭'）或脸谱化反派。 |
| 情绪颗粒 | 1 | 情感表达是否具象化而非概念化。9-10分：用细节传递情绪（如李恪嫌马车颠簸体现现代身体记忆）；5分以下：直接陈述感受（'他感到愤怒'）或空洞口号。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "历史脑洞"
```

`--genre` 会把 `assets/prompts/男频/历史脑洞.txt` 追加到默认写作规范之后。（本题材的规则层目前只有套路和评分维度，没有迭代出的细则。）
