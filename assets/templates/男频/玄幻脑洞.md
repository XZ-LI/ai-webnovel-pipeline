# 玄幻脑洞（男频）写作模版

英文名：Fantasy Brain Holes
成熟度：**B 级** — 有语料库反推的评分维度，写作规则未迭代

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 对经典修仙/玄幻套路的颠覆或戏仿
- 主角用反常规逻辑解掉别人解不掉的局
- 设定荒诞但内部自洽的世界观
- 对网文老梗的讽刺
- 战力与情节急速升级，用于制造喜剧或震撼

## 推荐开局钩子

主角对一个死局给出的荒诞解法

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 钩子强度 | 3 | 开篇是否在300字内建立强烈阅读动机。9-10分：用反常设定、生死危机或颠覆性金句瞬间抓住读者；5分以下：平铺直叙背景或冗长世界观说明。 |
| 脑洞新颖 | 3 | 核心设定是否突破传统玄幻套路。9-10分：机制自洽且具颠覆性（如长生但每年+1点）；5分以下：换皮系统文或复用烂俗金手指（如开局送神装）。 |
| 人设鲜活 | 3 | 主角是否具备记忆点与行为逻辑。9-10分：通过细节动作/语言展现性格（如陈浔画饼复仇）；5分以下：标签化人设（如纯恶反派）或言行矛盾。 |
| 节奏把控 | 2 | 信息释放与事件推进是否张弛有度。9-10分：日常与危机交替（如种田→茅屋被烧）；5分以下：长时间无冲突流水账或密集打斗无喘息。 |
| 世界融合 | 2 | 玄幻元素是否自然嵌入叙事。9-10分：修仙规则影响人物抉择（如凡人见修士需行礼）；5分以下：境界/宗门等设定仅作名词堆砌。 |
| 悬念设计 | 2 | 是否埋设有效钩子引导追读。9-10分：章末留反转或未解谜题（如婴儿澡盆漂流）；5分以下：章节结束于平淡日常无期待感。 |
| 代价真实 | 2 | 机缘获取是否伴随合理风险。9-10分：力量提升付出惨痛代价（如手骨折）；5分以下：无痛升级或惩罚与收益严重失衡。 |
| 反差营造 | 2 | 是否善用预期违背制造趣味。9-10分：表面人设与实际能力错位（如炼气期露腹肌）；5分以下：主角言行完全符合常规强者模板。 |
| 对话自然 | 1 | 角色语言是否符合身份与情境。9-10分：方言/职业用语贴合人设（如铁匠夸“有铁匠之姿”）；5分以下：全篇书面语或强行玩梗。 |
| 情感共鸣 | 1 | 能否引发读者共情。9-10分：小人物困境真实（如饿到吃野菜）；5分以下：情绪空洞或强行煽情。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "玄幻脑洞"
```

`--genre` 会把 `assets/prompts/男频/玄幻脑洞.txt` 追加到默认写作规范之后。（本题材的规则层目前只有套路和评分维度，没有迭代出的细则。）
