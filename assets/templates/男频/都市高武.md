# 都市高武（男频）写作模版

英文名：Urban High Martial Arts
成熟度：**B 级** — 有语料库反推的评分维度，写作规则未迭代

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 武道在现代进化到超人层级的世界
- 榜单、擂台、国家级乃至全球级武道赛事
- 主角藏着远高于同辈的境界或隐伤
- 街头斗殴与高层权力斗争交织
- 古武传承藏在现代家族或学校里

## 推荐开局钩子

主角刻意压制的实力意外暴露

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 钩子强度 | 3 | 开篇是否在300字内建立强烈悬念或异常情境，引发读者追问‘为什么’。9-10分：以超常事件+身份错位瞬间抓住注意力；5分以下：平铺直叙日常，无异常点或冲突延迟超过500字。 |
| 矛盾锐度 | 3 | 核心冲突是否尖锐且具高武特色（如神性侵蚀、灾厄污染、信仰对立）。9-10分：矛盾直接关联生存/认知/人性底线，且具品类独有设定；5分以下：仅普通人际摩擦或泛泛‘变强打脸’。 |
| 人设辨识 | 3 | 主角是否具备高武语境下的独特行为逻辑或精神特质。9-10分：言行体现世界观烙印（如灾厄感知、神性负担）；5分以下：性格标签化（如单纯热血/嘴贱）无世界观互动。 |
| 世界渗透 | 3 | 世界观设定是否通过细节自然渗入叙事而非说明文。9-10分：规则/灾难/力量体系通过角色行为、环境、对话隐现；5分以下：大段背景解说或设定名词堆砌。 |
| 节奏张力 | 2 | 章节内是否形成‘异常→探索→新危机’的紧凑循环。9-10分：每800字内至少一次情绪或信息转折；5分以下：长时间静态描写或对话堆砌无推进。 |
| 悬念密度 | 2 | 每千字是否埋设至少1个可延展的谜题（非单纯‘他是谁’）。9-10分：悬念具多层解读空间（如身份/记忆/规则漏洞）；5分以下：悬念单一或答案过于直白。 |
| 代价显性 | 2 | 高武力量或机缘是否伴随清晰代价或风险。9-10分：每次能力使用/奇遇均揭示生理、精神或社会成本；5分以下：力量获取无代价或代价模糊。 |
| 对话功能 | 2 | 对话是否同时推进剧情、揭示性格、暗示世界观。9-10分：每段对话至少承载两项功能；5分以下：纯情绪发泄或信息重复。 |
| 异常合理 | 2 | 超自然现象是否在章节内提供初步‘内部逻辑’解释。9-10分：异常事件符合已展示的世界规则；5分以下：纯为猎奇而设，无因果链条。 |
| 情绪锚点 | 1 | 是否在高概念设定中植入可共情的人性瞬间。9-10分：角色在神性/灾厄压力下展现脆弱、坚守或荒诞温情；5分以下：全程冷静算计或无差别杀戮。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "都市高武"
```

`--genre` 会把 `assets/prompts/男频/都市高武.txt` 追加到默认写作规范之后。（本题材的规则层目前只有套路和评分维度，没有迭代出的细则。）
