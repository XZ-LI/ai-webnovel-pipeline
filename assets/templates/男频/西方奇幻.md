# 西方奇幻（男频）写作模版

英文名：Western Fantasy
成熟度：**A 级** — 已迭代 10 轮，采用第 8 轮（评审分 7.6）

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 中世纪欧式背景：骑士、法师、精灵、龙
- 职业分化的魔法体系或类 RPG 的升级体系
- 地下城探索与猎魔公会
- 预言、天选之子，或重生为弱小贵族
- 教会、王权、魔法势力三方角力

## 推荐开局钩子

主角第一次下地下城，或第一次在贵族宫廷露面

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 钩子强度 | 3 | 章节开头是否能迅速抓住读者的注意力并引发兴趣。 |
| 人物鲜活度 | 3 | 角色是否具有鲜明的个性和独特的魅力，能否让读者产生共鸣。 |
| 悬念设计 | 3 | 章节内悬念的设置是否巧妙，能否激发读者的好奇心。 |
| 世界观融合 | 3 | 世界观的设定与情节是否紧密结合，是否能让读者信服。 |
| 节奏变化 | 2 | 章节内情节推进的快慢是否合理，能否保持读者的持续兴趣。 |
| 画面感 | 2 | 描写是否生动，能否让读者在脑海中形成清晰的画面。 |
| 对话自然度 | 2 | 人物对话是否符合角色身份，是否自然流畅。 |
| 情感张力 | 2 | 情感描写是否能引发读者的情绪波动，增加阅读的投入感。 |
| 章节差异度 | 2 | 各章节之间是否有足够的变化和新意，避免重复和单调。 |
| 外形描写 | 1 | 对角色和场景的外形描写是否生动具体，能否增强画面感。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "西方奇幻"
```

`--genre` 会把 `assets/prompts/男频/西方奇幻.txt` 追加到默认写作规范之后。
