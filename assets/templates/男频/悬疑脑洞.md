# 悬疑脑洞（男频）写作模版

英文名：Mystery Brain Holes
成熟度：**B 级** — 有语料库反推的评分维度，写作规则未迭代

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 极端解谜设定（密室、逻辑陷阱）
- 反转会重新定义前文读过的所有场景
- 不可靠的时间线或视角
- 规则隐藏的高危游戏或竞赛
- 社会工程与心理操控被当成破局工具

## 推荐开局钩子

主角被摆上一道看起来无解的谜题

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 钩子强度 | 3 | 开篇是否在300字内建立强烈悬念或异常情境，迫使读者继续阅读。9-10分：首段即呈现无法解释的诡异现象、死亡威胁或认知颠覆；5分以下：平铺直叙背景设定、角色日常或冗长心理描写。 |
| 规则张力 | 3 | 是否清晰呈现不可违背的诡异规则及其致命后果。9-10分：规则具体、矛盾、可验证，且与角色生死直接挂钩；5分以下：规则模糊、可随意打破，或仅作为背景说明无实际约束力。 |
| 反转密度 | 3 | 单位篇幅内有效反转的数量与质量。9-10分：每章至少1次逻辑自洽的颠覆性转折（如身份错位、规则误读、盟友背叛）；5分以下：情节线性推进，悬念靠信息遮蔽而非逻辑重构。 |
| 求生逻辑 | 3 | 角色应对危机是否基于观察与推理而非运气或外挂。9-10分：行动链完整（观察→假设→验证→修正），失败亦有教训；5分以下：靠系统提示、突然觉醒或巧合脱险。 |
| 脑洞锐度 | 3 | 核心设定是否具备新颖性与延展性。9-10分：概念简洁但能衍生多重解读（如'造神游戏''规则赌约'）；5分以下：套用常见模板（如无限流副本+积分兑换）无独特机制。 |
| 认知颠覆 | 2 | 是否通过细节揭示世界观底层逻辑的异常。9-10分：用微小观察（如钟表、衣物、身体变化）暗示现实扭曲；5分以下：依赖旁白直述'这是诡异世界'，缺乏具象锚点。 |
| 氛围渗透 | 2 | 环境描写是否持续强化不安感。9-10分：感官细节（气味、触感、声音）与空间异常结合，形成压迫性场域；5分以下：仅用'阴森''恐怖'等抽象词，或场景切换突兀无延续性。 |
| 代价显性 | 2 | 失败后果是否具体、即时、不可逆。9-10分：死亡/惩罚伴随生理细节（如脑组织跳动、人皮悬挂）；5分以下：仅提示'扣除生命值'或模糊消失。 |
| 对话功能 | 2 | 对话是否推动剧情或暴露角色特质。9-10分：每句台词含信息增量（如揭露矛盾、试探立场）；5分以下：寒暄、重复已知信息或纯情绪宣泄。 |
| 系统融合 | 1 | 若有系统/直播等元设定，是否有机嵌入叙事。9-10分：系统规则与怪谈逻辑同源，直播反应反哺主角策略；5分以下：系统独立于剧情，仅作数值展示或解说工具。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "悬疑脑洞"
```

`--genre` 会把 `assets/prompts/男频/悬疑脑洞.txt` 追加到默认写作规范之后。（本题材的规则层目前只有套路和评分维度，没有迭代出的细则。）
