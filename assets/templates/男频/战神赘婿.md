# 战神赘婿（男频）写作模版

英文名：War God / Underestimated Son-in-Law
成熟度：**B 级** — 有语料库反推的评分维度，写作规则未迭代

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 深藏不露的主角以上门女婿身份隐姓埋名
- 持续被羞辱，再迎来戏剧性揭底
- 军方或地下世界的恐怖背景逐步揭开
- 旧部下一个接一个登门，震慎岳家
- 打脸时刻：主角真实身份被当众曝光

## 推荐开局钩子

第一次当众受辱，同时露出一丝真实实力的苗头

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 钩子强度 | 3 | 开篇是否在300字内建立强烈情绪驱动的危机事件，直接关联主角最珍视之人（女儿/妻子/恩人）。9-10分：电话求救、骨灰受辱等瞬间引爆共情；5分以下：平淡日常或缓慢铺垫背景。 |
| 战神威压 | 3 | 主角或其势力展现压倒性武力时的描写是否具象且震撼。9-10分：气势破云、千人跪拜等超规格场面；5分以下：仅用‘很强’‘无敌’等抽象词，无视觉化呈现。 |
| 亲情锚点 | 3 | 主角行动是否紧密围绕保护/拯救至亲（尤其女儿）展开。9-10分：女儿受虐细节+主角泪崩反应形成情感闭环；5分以下：亲情沦为口号，无具体互动或牺牲动机。 |
| 爽感兑现 | 3 | 章节结尾是否完成阶段性复仇或碾压。9-10分：反派被瞬秒、敌营被奇袭端掉；5分以下：仅埋下伏笔无实质成果，读者情绪悬空。 |
| 节奏爆点 | 2 | 每千字是否包含至少一个高能反转或暴力宣泄节点。9-10分：求救→飙车→全球强者集结→反派暴行穿插推进；5分以下：大段背景解说或静态对话拖慢叙事。 |
| 反派践踏 | 2 | 反派是否对主角珍视之物（女儿、骨灰、尊严）进行具象羞辱。9-10分：吐痰于烈士骨灰盒、摔碎女儿手机；5分以下：反派仅言语挑衅，无实质性伤害行为。 |
| 身份反差 | 2 | 主角表面卑微（赘婿/退役兵）与真实身份（战神/殿主）的对比是否尖锐。9-10分：机场路人无视vs千军跪迎；5分以下：身份揭露过早或缺乏社会性轻视铺垫。 |
| 世界联动 | 2 | 主角行动是否引发全球/全国级势力连锁反应。9-10分：一通电话致三千强者齐赴华夏；5分以下：冲突仅限本地小混混，无宏观格局呼应。 |
| 情感代价 | 2 | 主角过往是否因守护他人而承受重大牺牲（跳江、中毒、背负骂名）。9-10分：为复仇离开心上人致其独自产女；5分以下：主角无情感创伤，动机单薄。 |
| 系统赋能 | 1 | 若有系统/金手指，是否在绝境中即时提供战术或力量突破。9-10分：炮火覆盖时激活‘超级蓝军系统’注入知识；5分以下：系统功能模糊或延迟生效，无助于当前危机。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "战神赘婿"
```

`--genre` 会把 `assets/prompts/男频/战神赘婿.txt` 追加到默认写作规范之后。（本题材的规则层目前只有套路和评分维度，没有迭代出的细则。）
