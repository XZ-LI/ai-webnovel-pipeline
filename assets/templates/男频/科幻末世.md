# 科幻末世（男频）写作模版

英文名：Sci-Fi / Post-Apocalypse
成熟度：**B 级** — 有语料库反推的评分维度，写作规则未迭代

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 尸潮爆发、外星入侵或环境崩坏
- 幸存者基地、资源稀缺、派系战争
- 异能觉醒体系（主角拿到稀有或逆天的能力）
- 重压之下的人性下坠或人性坚守
- 残存科技与末世前真相的挖掘

## 推荐开局钩子

末世第一天，以及主角的觉醒

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 末世钩子 | 3 | 开篇是否在300字内建立紧迫、具象的末日危机，让读者立刻感知生存威胁。9-10分：危机具体、倒计时明确、感官细节强烈；5分以下：仅泛泛提及‘末日来了’，无时间压力或物理实感。 |
| 金手指合理性 | 3 | 系统/异能/重生等超常设定是否与末世逻辑自洽。9-10分：能力有明确限制、代价或成长路径，且与世界观融合；5分以下：能力凭空出现、无限叠加、无视末世资源约束。 |
| 节奏张力 | 3 | 章节推进是否保持危机-行动-反馈的紧凑循环。9-10分：每千字至少一次小高潮或决策点；5分以下：大段回忆、说明或日常描写打断生存紧迫感。 |
| 科技可信度 | 2 | 科幻元素是否具备基础科学逻辑或内部一致性。9-10分：技术演进有阶梯（如可控核聚变→曲率航行），或明确设定技术遗失背景；5分以下：混用不兼容科技（如AI全知却不会造电池），无视物理常识。 |
| 人物动机 | 2 | 主角行为是否有清晰、可共情的末世驱动。9-10分：动机源于生存、亲情或创伤记忆，且与末世环境强相关；5分以下：行为只为装逼或无理由杀戮，缺乏情感根基。 |
| 世界细节 | 2 | 末世环境是否通过具体物象呈现（温度、气味、货币、建筑等）。9-10分：用3个以上独特细节构建可信废土/星际生态；5分以下：仅用‘丧尸’‘废墟’等泛称，无差异化设定。 |
| 反转密度 | 2 | 章节内是否包含至少一次有效剧情转折。9-10分：反转推动主线（如重生→识破阴谋→反杀）；5分以下：无转折或仅为情绪波动（如‘他很愤怒’但无行动变化）。 |
| 资源逻辑 | 2 | 物资、能源、人力等稀缺资源是否影响角色决策。9-10分：主角行动受资源制约（如钱不够只能囤万吨猪肉而非十万吨）；5分以下：资源无限或获取无成本（如随手买下整座超市）。 |
| 对话功能 | 1 | 对话是否传递信息、暴露性格或推进冲突。9-10分：每句对话有潜台词或改变局势；5分以下：对话仅为交代背景（如‘你知道吗，末日要来了’）或无意义寒暄。 |
| 情感锚点 | 1 | 是否建立读者可共情的情感支点（亲情、遗憾、执念）。9-10分：情感与末世生存强绑定（如为护弟妹冒险）；5分以下：情感线突兀插入（如末日当天谈校园恋爱）。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "科幻末世"
```

`--genre` 会把 `assets/prompts/男频/科幻末世.txt` 追加到默认写作规范之后。（本题材的规则层目前只有套路和评分维度，没有迭代出的细则。）
