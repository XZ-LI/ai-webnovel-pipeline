# 抗战谍战（男频）写作模版

英文名：Anti-Japanese War / Spy Thriller
成熟度：**B 级** — 有语料库反推的评分维度，写作规则未迭代

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 1930–40 年代中国，沦陷区与抵抗力量
- 双面间谍、密电、深潜任务
- 道义上的灰色：家国忠诚与活命之间的拉扯
- 阵营还原：国民党、共产党、日军、伪政权
- 紧绷的渗透任务与一线脱身

## 推荐开局钩子

主角第一次任务就差点被揭穿身份

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 钩子强度 | 3 | 开篇是否在300字内建立强烈悬念或冲突，引发读者继续阅读欲望。9-10分：开篇即呈现生死危机、身份反转或超常能力觉醒；5分以下：冗长背景铺垫、无冲突日常描写或作者自白式说明。 |
| 身份张力 | 3 | 主角是否具备多重身份或隐藏立场带来的内在冲突。9-10分：身份矛盾贯穿行为逻辑（如表面医生实为红党）；5分以下：身份单一、无秘密或仅靠系统外挂支撑。 |
| 节奏密度 | 3 | 单位篇幅内信息量与情节推进效率。9-10分：每千字至少包含一个关键转折或新情报（如发现日谍、审讯突破）；5分以下：大量无效对话、重复心理描写或场景停滞。 |
| 敌我博弈 | 3 | 是否展现情报战特有的智斗与反制逻辑。9-10分：行动基于情报分析、心理预判或制度漏洞（如利用医疗权威拖延审讯）；5分以下：依赖巧合、敌人降智或武力碾压。 |
| 危机嵌套 | 3 | 是否叠加多重时间压力或任务冲突。9-10分：同时面临外部追捕、内部审查、时限任务等复合危机；5分以下：单一威胁线性推进。 |
| 时代质感 | 2 | 是否通过细节真实还原民国抗战时期的社会肌理。9-10分：物价、制度、服饰、语言等细节精准且自然融入叙事；5分以下：时空错乱（如现代词汇泛滥）、历史常识错误或完全架空无依据。 |
| 机缘代价 | 2 | 主角获得能力或机遇是否伴随合理风险与限制。9-10分：金手指有明确使用成本或道德困境（如扫描眼初期无用、手术系统需救人才获情报）；5分以下：能力无代价、无限使用或纯福利型系统。 |
| 人物弧光 | 2 | 角色是否在章节内展现动机驱动的行为变化。9-10分：行为受清晰目标/创伤驱动（如复仇誓言、信仰危机）；5分以下：行为随机、动机模糊或仅为剧情工具人。 |
| 悬念闭环 | 2 | 章节结尾是否设置可验证的短期悬念。9-10分：悬念具象且下章可解（如‘红党将营救，我已备好打火机’）；5分以下：开放式感叹、无指向性期待或强行断章。 |
| 组织生态 | 2 | 是否呈现情报/军政系统的层级规则与派系斗争。9-10分：机构运作符合历史逻辑（如力行社vs中统、医院与租界关系）；5分以下：组织功能模糊、权力结构儿戏化。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "抗战谍战"
```

`--genre` 会把 `assets/prompts/男频/抗战谍战.txt` 追加到默认写作规范之后。（本题材的规则层目前只有套路和评分维度，没有迭代出的细则。）
