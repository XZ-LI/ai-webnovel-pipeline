# 都市修真（男频）写作模版

英文名：Urban Cultivation
成熟度：**B 级** — 有语料库反推的评分维度，写作规则未迭代

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 古代修士重生或穿越到现代都市
- 隐世宗门在现代社会的夹缝里运转
- 主角一边应付上学上班，一边修炼
- 炼丹炼器被迫适配现代资源
- 古修世界与现代体制的正面碰撞

## 推荐开局钩子

主角在现代语境里第一次发现修真的存在

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 钩子强度 | 3 | 开篇是否在300字内建立强烈阅读动机。9-10分：用命运转折、生死危机或超常设定瞬间抓住读者；5分以下：平铺直叙背景介绍，无紧迫感或悬念。 |
| 矛盾锐度 | 3 | 核心冲突是否尖锐且具都市修真特色（如凡俗规则vs修真力量、因果业力vs现代法律）。9-10分：矛盾不可调和，涉及生死、尊严或大道之争；5分以下：冲突模糊或可轻易化解。 |
| 节奏张力 | 3 | 章节内是否保持‘平静-危机-解决/新危机’的波浪式推进。9-10分：每千字至少一次情绪起伏，打斗/诊断/反转密集；5分以下：长时间静态描写或对话堆砌。 |
| 机缘合理 | 2 | 主角获得能力/资源是否符合修真逻辑（需付出代价或承担因果）。9-10分：机缘伴随明确限制、反噬或责任；5分以下：无条件赠予，无视修真世界平衡法则。 |
| 人设辨识 | 2 | 角色是否通过细节展现独特修真身份（非脸谱化）。9-10分：言行体现门派/功法特质（如道医重阴阳、武修重杀伐）；5分以下：角色仅靠标签（如‘老道长’‘美女师姐’）存在。 |
| 世设融合 | 2 | 修真元素是否自然嵌入都市场景（非生硬拼接）。9-10分：修真逻辑解释现代问题（如用符咒治网红病、宗门影响金融）；5分以下：修真与都市平行存在，互不干涉。 |
| 反转密度 | 2 | 章节内是否设置符合逻辑的意外转折。9-10分：每章至少1次颠覆预期（如患者实为妖物、恩人竟是仇家）；5分以下：线性叙事无波澜。 |
| 对话锋芒 | 2 | 对话是否推动剧情或暴露角色立场。9-10分：每句对话含潜台词或利益博弈；5分以下：纯信息搬运（如‘我是来看病的’）。 |
| 情绪锚点 | 2 | 是否建立让读者共情的核心情感（如复仇执念、济世仁心）。9-10分：情感贯穿始终并驱动行为；5分以下：情绪单薄或频繁切换。 |
| 代价显性 | 1 | 主角使用能力是否呈现明确消耗或后果。9-10分：施术需耗精血/折寿/引天劫；5分以下：能力无限使用无负担。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "都市修真"
```

`--genre` 会把 `assets/prompts/男频/都市修真.txt` 追加到默认写作规范之后。（本题材的规则层目前只有套路和评分维度，没有迭代出的细则。）
