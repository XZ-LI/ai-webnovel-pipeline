# 悬疑灵异（男频）写作模版

英文名：Mystery / Supernatural Thriller
成熟度：**B 级** — 有语料库反推的评分维度，写作规则未迭代

## 读者预期与核心套路

读者点进这个品类就是为了看这些，要兑现：

- 身份特殊的主角接手灵异案件
- 鬼神、诅咒、阴间都有一套隐藏规则
- 不可靠叙述 + 慢热式揭秘
- 民俗与神话生物被搬进现代场景
- 生存恐怖元素，筹码层层加码

## 推荐开局钩子

一个物理上不可能的现场，或与超自然的首次正面接触

## 立项时必须定下来的

除了 `assets/premise_template.txt` 里的通用字段，这个题材还要特别问清：

- 上面每条套路，这本书是照着写、反着写，还是换个壳？逐条给个说法，全部照搬会像同人，全部反写会丢掉读者来看的东西。
- 主角的核心优势从第几章开始显形？太晚读者会走。
- 第一个让读者“憋着一口气想看下一章”的点，落在第几章？

## 质量自检表

这些维度是从本题材高分作品里反推出来的。写完一章拿它逐项过，权重高的先看。

| 维度 | 权重 | 看什么 |
|---|---|---|
| 钩子强度 | 3 | 开篇是否在300字内建立强烈悬念或异常事件，引发读者继续阅读的冲动。9-10分：首段即出现超自然现象、死亡威胁或命运转折；5分以下：平铺直叙背景设定，无即时危机或异常。 |
| 灵异真实感 | 3 | 对灵异体系、术语、仪式的描写是否具备细节支撑和内在逻辑。9-10分：使用真实民俗术语（如‘捆仙绳’‘四梁八柱’）并解释其来源与限制；5分以下：灵异元素凭空出现，无规则、无代价、无文化根基。 |
| 悬念设计 | 3 | 是否设置可延展的谜题，且提供部分线索引导读者推理。9-10分：谜题具象（如'天花板滴水杀人'），并给出观察依据；5分以下：仅用'好可怕''不知道是什么'等模糊描述制造悬念。 |
| 节奏张力 | 2 | 章节内是否维持悬疑推进的紧迫感，避免冗长说明打断叙事流。9-10分：每500字至少有一次危机升级或信息反转；5分以下：大段世界观解说插入动作场景，导致节奏停滞。 |
| 人物动机 | 2 | 角色行为是否有清晰且符合人设的驱动力，尤其面对灵异威胁时。9-10分：主角行动源于生存、执念或因果（如救弟、还债、避劫）；5分以下：为推动剧情强行作死或无理由涉险。 |
| 代价呈现 | 2 | 灵异能力或介入是否伴随明确风险、业障或反噬。9-10分：强调因果律（如'担业障无法轮回'）或使用限制；5分以下：能力无代价，主角随意驱邪无后果。 |
| 画面冲击 | 2 | 恐怖或诡异场景是否具备强视觉与感官描写。9-10分：融合触觉、听觉、嗅觉细节（如'黑血咕嘟冒泡''蜈蚣咬住伤口'）；5分以下：仅用'很恐怖''吓死了'等抽象表述。 |
| 世界观融合 | 2 | 灵异设定是否自然嵌入社会背景，而非孤立存在。9-10分：将灵异与时代（如80年代东北）、制度（如邮局鬼差）、经济（末世物资）结合；5分以下：灵异事件与现实世界完全脱节。 |
| 反转合理性 | 2 | 剧情转折是否有伏笔支撑，避免机械降神。9-10分：反转前埋设细节（如弟弟少一魂暗示觉醒）；5分以下：突然出现新能力或帮手解决危机，无前期铺垫。 |
| 对话功能 | 1 | 对话是否推动剧情、揭示性格或传递关键信息。9-10分：每段对话含潜台词或信息增量（如试探、警告、误导）；5分以下：对话仅为寒暄或重复已知信息。 |

## 怎么用

```bash
python3 $SK/write_novel.py write --project "<书名>" --genre "悬疑灵异"
```

`--genre` 会把 `assets/prompts/男频/悬疑灵异.txt` 追加到默认写作规范之后。（本题材的规则层目前只有套路和评分维度，没有迭代出的细则。）
