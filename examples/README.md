# 真实产出样例

这里是这套流水线实际跑出来的东西，不是挑出来的最佳片段。放出来是为了让你**在装之前先判断质量能不能接受**——架构说得再好，不如直接读两章。

## 这本书是怎么来的

《众神低语者》，西方奇幻，男频。从零开始，全程如下：

1. 作者只给了一句话：**「男主角是成长路线」**
2. 流水线按这句话出了 3 个方案（金手指和核心矛盾互不相同），作者挑了"多神低语换取奇迹，代价是理智崩裂"那个
3. 展开成大纲加第一章，建项目，生成故事圣经
4. 往下续写

模型全程是 **o3**（OpenAI）。这是早期跑的，现在的默认是 DeepSeek——同一套流程换模型只要一条命令。

## 该看什么

**`chapters/001.txt`** — 立项时产出的第一章。注意主角伊利亚是哑巴：全章没有一句出声的台词，交流靠心声、手势和铜铃。

**`chapters/008.txt`** — 人物章。这一章**没有战斗、没有追兵、没有逃亡**，是两个人在驿站里互相试探。章型轮换带着禁止项，就是为了不让慢节奏的章节被"每章都要有冲突"推成动作戏。

**`chapters/009.txt`** — 感情章。开篇是对话（`「让开，是我。」`），和上一章的环境开篇不同——系统会扫最近两章的开篇手法并要求避开重复。主角依然不出声：`轻敲铜铃回应`、`抬指比了个"还活"`。

**`bible.json`** — 故事圣经，最值得读的是两段：

- `hard_constraints`：六条"违反即整章作废"的红线。第一条就是"伊利亚不能说话"。这条是**事后补的**——最初没写进去，第三章他就开口说了四次话。
- `open_threads`：伏笔台账。每章写完自动登记新埋的、勾掉兑现的，埋过 30 章会在提示词里标注"该考虑兑现了"。

**`summaries.jsonl`** — 每章两三句的压缩。只有最近 10 章进上下文，更早的靠圣经、台账和弧线提要承载。

**`arc_plan.txt`** — 第 1 弧（1–30 章）的逐章计划。注意第 1 章写的是"已定稿，不改动"——弧线计划不会重写已经写好的章节。

## 对照组

`对照/` 下是**同一个项目复制一份、唯一变量是不带 `--genre` 题材模版**写出的同编号章节。两组的故事圣经、弧线计划、前 7 章完全一致（文件哈希相同），所以差异只来自模版。

自己读了比看我的结论可靠。我的测量是：

| | 带模版 | 不带 |
|---|---|---|
| 评分（写手自评 o3） | 7.52 | 7.30 |
| 评分（换独立评委 gpt-4o） | 7.75 | 7.70 |
| 三章平均段长 | 19.9 / 20.0 / 19.7 字 | 10.4 / 33.2 / 33.0 字 |
| 字数 | 2544 / 2713 / 3302 | 2358 / 3011 / 4509 |

**分数差太小，不足以说明模版让质量变好**——换个评委就从 +0.22 缩到 +0.06。真正稳定的差异是章与章之间的**段落形态一致性**：带模版那组三章的平均段长几乎不动，不带那组在 10.4 和 33.2 之间来回摆。对连载来说这是实在的阅读体验差异，但它不是"写得更好"，是"写得更稳"。

## 诚实的话

- 这些章节的诊断得分在 **7.2–7.8** 之间（10 分制，按西方奇幻题材自己的评分维度）。不是惊艳，是"达到行业基本功"。
- 第 9 章带模版那版曾经在正文里漏出过一行写作提示（`（十五字解释他童年……满足动机补位）`）——题材规则里的术语被模型抄进了正文。那是盲评发现的，诊断器没抓到。现在清洗器能剥掉这类标签，仓库里这份是清洗后的。
- 评分维度本身的效度有限：这类评分表重测信度高，但与读者真实行为的相关性很弱（见 [llm-rubric-validity](https://github.com/XZ-LI/llm-rubric-validity)）。所以别把 7.6 分当成"读者会喜欢"。

一句话：这套东西保证的是**不出技术性事故**——设定不矛盾、哑巴不说话、字数不失控、伏笔不失忆。好不好看，要你自己读了判断。
